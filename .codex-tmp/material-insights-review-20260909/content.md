# 素材洞察与数据源产品优化方案

产品评审与原型设计依据

版本 V1.0　日期 2026年9月9日

本方案面向产品、设计、运营和研发评审，覆盖素材洞察的有数据状态、空状态，以及数据源的账户接入与管理。业务链路从连接 TikTok 广告账户开始，经过选择同步范围、首次同步、查看商品与素材表现，最终形成可执行的素材改版任务。

**核心结论**

第一优先级是让用户在素材洞察首屏完成账户接入，并让每种无数据情况都有明确的下一步。第二优先级是合并重复菜单与报表。第三优先级是修正诊断口径，让运营看懂证据，设计师拿到具体修改要求。

**建议采用的页面结构**

“洞察 → 素材洞察”下保留“经营总览、素材表现”两个页签；素材诊断通过详情承载，疲劳通过筛选进入。“设置 → 数据源”继续负责长期账户管理，同时在素材洞察首屏和账户选择器提供连接入口。创意任务使用现有“任务”模块承接。

**本轮范围**

仅包括素材洞察、数据源及二者到现有创作和任务模块的衔接规则。不包含品牌追踪，不制作原型图，不展开接口、数据库或实现架构。文中的新行为均为产品优化建议，未上线能力应按可用性分阶段开放。

**评审材料编号**

本轮空状态截图记为 E01 至 E08，分别对应 Dashboard、素材360、疲劳监测、GMV Max经营总览、GMV Max素材诊断、投放中心、任务记录、数据源。前轮有数据截图记为 D01 至 D05，与前五类页面对应。后续问题可按编号定位。

**成功标准**

新用户在首次进入素材洞察时即可找到“连接 TikTok 广告账户”；授权返回后能继续完成同步；老用户遇到异常时知道是账户、同步、筛选还是样本问题；运营能解释为什么建议改版，设计师能指出具体改动和保留内容。

# 1 核心问题与优先级

P0 为影响接入、数据理解或诊断可信度的问题。P1 为影响导航与日常效率的问题。P2 为基础链路稳定后补充的能力。

| 问题与位置 | 原因及用户影响 | 优化建议 |
| --- | --- | --- |
| P0 授权入口较深 E01 E08 | 用户先看到空图表，不知道数据需要接入，也不容易联想到设置中的数据源。 | 首屏提供明确价值说明和连接按钮，授权与同步完成后回到原入口。 |
| P0 空状态解释不一致 E01至E05 | 有的说无趋势，有的说未启用同步，有的让用户调整筛选，用户无法定位问题。 | 先识别账户与同步状态，再判断范围和样本；使用统一状态规则。 |
| P0 无数据被解释为经营结论 E03 E05 | 疲劳分0.0配“正常”，素材供给0条触发健康线6条警告，容易导致错误行动。 | 数据未就绪时不产生正常、疲劳、供给不足等判断。 |
| P0 授权成功与可分析混为一谈 E02 E08 | 用户可能已授权，但未选择账户、未启用同步或首轮未完成。 | 分开展示连接状态、同步状态、可分析范围，并为每一步提供恢复入口。 |
| P0 报表数值与口径不一致 D01 D04 | 同为花费40.59美元，点击与转化展示不同，影响信任。 | 统一时间、账户、商品及指标口径；无法对齐时明确范围差异。 |
| P0 低样本仍给强结论 D02至D05 | 零或极低消耗素材被评为优质，样本未成熟却推断素材问题。 | 区分内容结构评价、投放观察和数据支持的诊断，展示证据充分程度。 |
| P1 菜单与页签重复 全部洞察页 | Dashboard与经营总览、素材360与素材诊断、疲劳与阶段分类交叉。 | 收敛为经营总览和素材表现，详情承载深入诊断。 |
| P1 未上线页面占主路径 E06 E07 | 用户点入后看到内部研发说明，无法继续工作。 | 隐藏未开放入口，能力上线后接入现有任务或创作流程。 |
| P1 账户和素材主要用ID表达 D02 D05 E04 | 运营难识别账户，设计师难识别视频与商品。 | 使用名称、封面和商品信息，ID只保留复制与查验用途。 |
| P1 观察对象挤占待处理列表 D03 D04 | “继续观察”被当作动作，962个观察商品淹没真正问题。 | 默认展示需处理对象，观察对象单独筛选并标明复核条件。 |

处理顺序建议为：账户接入与状态修正 → 页面合并 → 数据口径与证据诊断 → 创意任务衔接。数据可信度修正与接入改造可并行评审。

# 2 信息架构与菜单合并

**推荐方案**

保留左侧“洞察 → 素材洞察”，页面统一命名为“素材洞察”。顶部仅保留“经营总览、素材表现”。GMV Max与竞价广告作为投放模式选择，不再同时作为功能页签。“数据源”保留在设置中承担管理职责，并提供场景内的连接快捷入口。

| 当前入口 | 建议去向 | 用户获得的变化 |
| --- | --- | --- |
| Dashboard | 合并至经营总览 | 只需认一套汇总指标与趋势。 |
| GMV Max诊断 → 经营总览 | 合并至经营总览 | 按当前投放模式展示对应口径。 |
| 素材360 | 合并至素材表现 | 统一浏览、筛选和比较素材。 |
| GMV Max诊断 → 素材诊断 | 素材表现中的诊断状态及详情 | 看见问题后直接进入证据和建议。 |
| 疲劳监测 | 素材表现中的疑似疲劳筛选 | 保留能力，减少独立报表入口。 |
| 生命周期与优质标签 | 分成阶段筛选和诊断筛选 | 明确不同维度可以组合。 |
| 投放中心 | 当前隐藏；可用后从任务详情进入 | 不再进入只有“即将上线”的页面。 |
| 任务记录 | 合并到左侧任务模块的创意任务筛选 | 同一任务只维护一个记录。 |
| 设置 → 数据源 | 保留；洞察页增加快捷入口 | 新用户容易连接，老用户容易管理。 |

**统一筛选规则**

顶部只保留一组投放模式、账户或店铺、日期范围。先选择模式，再展示该模式可用的账户与店铺；不要求竞价广告用户必须有店铺。范围不兼容时说明原因并让用户选择，不静默跳到其他账户。商品、诊断状态、风格等局部条件放素材列表上方。

首次未连接时隐藏无意义的账户下拉、日期设置和空分类；保留页面名称及模块定位。跨页保留兼容的筛选条件，并显示具体起止日期。全部店铺汇总前明确币种、时区和可用范围，不能直接混加不同币种。

**方案取舍**

仅增加授权按钮的改动最小，但菜单与口径重复仍存在；重建独立诊断工作台的调整范围过大。推荐保留现有模块归属、合并页面职责，授权组件与数据源管理共用同一套状态和结果。

# 3 首次接入与返回流程

**业务流程**

进入素材洞察 → 识别当前连接与同步状态 → 连接平台账户 → 选择要接入的广告账户 → 按需确认店铺与数据范围 → 点击“开始同步” → 查看同步结果 → 进入经营总览或返回原素材页面。

1. 未接入时，首屏说明“连接后可查看商品与素材表现，并形成改版建议”，主按钮为“连接 TikTok 广告账户”。链接按钮直接开始接入流程，避免只告诉用户去设置查找。
2. 进入平台授权前，说明此次将读取哪些数据及实际申请的权限。产品文案必须与真实授权范围一致；本轮数据分析流程不因连接账户自动创建广告、修改预算或执行投放。
3. 平台授权成功后展示可选账户名称和辅助ID，由用户确认接入范围。默认不替用户全选多个账户；只有一个可选账户时可预选，仍在开始同步前展示范围。
4. 若 GMV Max 所需店铺或商品报表权限尚未具备，列出已具备和缺少的能力，只针对缺口补充授权或选择关联关系。不能承诺广告账户授权一次就必然获得全部店铺数据。
5. 用户确认范围并点击“开始同步”后，自动启用该范围的同步，避免再次跳到设置页寻找开关。明确同步的是报表数据，开关不控制广告是否投放。
6. 同步中展示真实阶段与更新时间，例如“正在读取广告表现”。没有可靠进度时不展示伪造百分比和倒计时。用户离开页面后任务继续，返回时恢复状态。
7. 首轮完成后区分有数据、真实无记录和部分成功。有数据时提供“查看洞察”；从具体素材入口发起连接的用户返回原上下文。

**取消与异常恢复**

用户取消授权后回到原页，保留连接入口，不自动重复弹出。授权成功但未完成账户选择时，提示“继续选择同步账户”。重复点击连接或同步时进入当前流程状态，不反复创建同一接入任务。

授权返回后没有可选账户时，明确提示“当前登录身份下没有可接入的广告账户”，提供切换平台身份或查看权限说明的入口；不能把空账户列表当成同步中。弹窗未能打开时提供重新打开授权页的操作，并保留当前流程。

**无账户管理权限的设计师**

工作空间中已有数据且设计师具备查看权限时，不要求其个人重新授权。缺少工作空间接入时提供“复制连接说明”供其联系管理员；产品不得替用户自动发送消息。有素材预览权限但无经营指标权限时，按现有角色规则展示对应内容，不用“无数据”掩盖无权限。

# 4 空状态规则 账户与同步

首先判断当前数据范围的接入状态。仅凭查询结果为空，不能推断用户没有授权。全局缺失采用页面级引导，单账户异常采用局部提示，不遮挡其他正常账户。

| 状态与识别条件 | 建议主文案 | 主操作与后续行为 |
| --- | --- | --- |
| ST01 未连接任何可用账户 | 连接 TikTok 广告账户，开始查看素材表现。 | 连接 TikTok 广告账户；隐藏空图表和诊断标签。 |
| ST02 已授权但未选择账户 | 已完成平台授权，请选择需要同步的广告账户。 | 选择账户；返回未完成的接入步骤。 |
| ST03 账户已连接但同步未启用 | 账户已连接，尚未开启数据同步。 | 开启同步；展示账户范围后开始。 |
| ST04 首次同步中 | 正在同步投放数据，完成后即可查看洞察。 | 查看同步进度；允许离开后继续。 |
| ST05 同步失败且没有历史数据 | 本次同步未完成，暂时无法展示洞察。 | 重试同步；展示可理解的失败原因。 |
| ST06 同步失败但有历史数据 | 本次更新失败，当前展示截至某时的数据。 | 重试同步；保留历史数据并标明时效。 |
| ST07 授权失效或被撤销 | 此账户连接已失效，请重新连接后更新数据。 | 重新连接；保留原账户和返回位置。 |
| ST08 权限或关联范围不足 | 已连接账户，当前缺少所选报表的访问权限。 | 补充授权或检查账户关联；不要求无差别重做全部授权。 |
| ST09 当前用户无接入管理权限 | 需要工作空间管理员连接广告账户。 | 复制连接说明；已有可读数据继续展示。 |

**状态表达约束**

连接、同步和分析就绪是三个独立状态。授权成功可以触发“已连接”提示，但不能立即显示“数据同步完成”。同步开关关闭后应显示“同步已暂停”，并告知历史数据的保留与时效规则。

未获得有效数据时不显示疲劳0分、健康、风险花费0、预计提升、优质素材或素材供给不足。按钮应与问题对应，账户未连接时不能优先建议修改日期，筛选无结果时不能优先建议重新授权。

# 5 空状态规则 范围与证据

当连接有效、同步完成后，再判断当前范围、数据覆盖及诊断样本。真实无记录、没有业务活动和某个字段缺失要分开处理。

| 状态与识别条件 | 建议主文案 | 主操作与展示规则 |
| --- | --- | --- |
| ST10 当前日期无投放记录 | 当前日期范围内未发现投放记录。 | 调整日期；若已知最近有数据日期，提供直接查看入口。 |
| ST11 局部筛选无结果 | 当前筛选下没有匹配的素材。 | 清除筛选；只清除局部条件，不改变账户或店铺。 |
| ST12 当前模式无数据 | 当前范围暂无 GMV Max 数据。 | 若另一模式确有数据，提供切换入口；不自动混用报表。 |
| ST13 同步完整但没有素材 | 当前已接入范围内尚无可分析素材。 | 查看接入范围；确认真实缺口后再引导补充素材。 |
| ST14 有数据但样本不足 | 已同步素材，当前证据不足以判断表现。 | 查看已有数据；说明观察原因和复核条件。 |
| ST15 个别指标不可用 | 该指标暂未提供，其他数据可正常查看。 | 查看口径说明；该字段显示未提供，不填0。 |
| ST16 数据有效且未发现异常 | 当前未发现需要处理的素材问题。 | 查看全部素材；展示检查范围和检查时间。 |
| ST17 部分账户同步成功 | 已更新部分账户，另有账户需要处理。 | 查看异常账户；总计注明纳入范围，避免误称全部。 |
| ST18 功能尚未开放 | 当前功能暂未开放。 | 从主导航隐藏；旧链接解释状态并引导返回可用页面。 |

**处理优先顺序**

先判断账户与权限，再判断同步是否完成，随后判断日期和筛选，最后判断是否满足诊断要求。旧数据与局部可用数据采用局部提示。只有同步成功、范围明确且样本足够时，才能显示“未发现异常”。

**数值规则**

真实0保留为0；缺失显示“未提供”；尚在处理显示“同步中”；不适用显示“不适用”。订单为0时CPO不能显示0；消耗为0时ROI不能显示0；0/0不能换算为健康或0%疲劳。同期或基准缺失时不计算环比、衰减和相对指数。

**示例数据规则**

如后续增加示例报告，必须由用户主动进入，并在所有页面持续标明“示例数据”。示例不混入真实指标、任务或授权完成统计，不允许通过示例结论直接执行投放动作。

# 6 Dashboard与经营总览优化

**对应页面**

E01、E04以及D01、D04。目标为合并成一个经营总览，解决第一次接入和每天判断重点商品两类任务。

**问题与原因**

空状态保留多块大面积图表和重复的“暂无数据”，还显示“点击上方指标”或“点击左侧标签”，但用户没有可点击内容。有数据时两套KPI与趋势分别存在，数值和含义又不一致。经营问题队列默认铺开大量待观察商品，削弱优先级。

**空状态调整**

未接入时以一块完整引导替代全部空报表。内容包含：连接账户能做什么、连接按钮、简短步骤、实际权限说明和账户管理入口。可保留经营总览与素材表现的页签，但切换后仍使用同一接入状态，不产生多套无数据提示。

**有数据调整**

顶部为统一范围与最后成功更新时间；随后展示花费、归因成交额、订单、ROI、CPO等与当前模式一致的指标。CTR、CVR和观看指标可按需查看。指标选中态只表示是否加入图表，不使用类似“校验成功”的勾号误导用户。

趋势图默认采用实际单位，金额按币种展示；不同单位分图或清楚区分坐标。避免将全0序列归一化为50%。显示完整日期、数据缺口和比较周期，不用平滑曲线制造未观测的变化。

“今天先处理什么”默认展示需要用户行动的商品，包含商品名、问题摘要、涉及花费或成交、证据程度和主操作。观察对象独立收纳。没有证据充分的异常时说明结果，不用生成动作数量营造待办。

**信息下沉**

标签花费排行、行业分布和Top素材移入创意复盘入口，仅在样本足够时出现。行业基准需说明来源、比较范围和样本；缺少来源时不显示“超过行业”。不以花费排序冒充素材效果排名。

**验收重点**

首次未接入时首屏能够开始连接；同一范围下各处花费和订单一致；真实无异常与没有数据有不同展示；从问题商品进入素材列表时自动带入商品与时间范围。

# 7 素材360与素材诊断优化

**对应页面**

E02、E05以及D02、D05。目标为合并成素材表现，既能浏览库存，又能判断当前范围内的表现。

**问题与原因**

E02已经提示没有启用同步，但只给文字路径；E05在无数据时触发“素材供给0条，低于健康线6条”。有数据时长ID占主视觉，很多行缺封面，结构评分与投放质量混用。历史库存数量、当前供给数量和参与诊断数量之间缺少解释。

**空状态调整**

未开启同步时直接提供“开启同步”。只有确认账户、商品范围和素材库存已完整读取后，才能判断供给是否不足。不能把截图中的6条健康线作为所有商品通用标准；若保留阈值，必须说明适用对象、统计范围和规则来源。

库存不足与近7天有消耗素材少分别表达。历史库存可以独立查看，但诊断与表现统计始终显示所选日期，避免“全部历史”与近7天口径混淆。

**列表默认字段**

| 字段组 | 默认展示 | 展开查看 |
| --- | --- | --- |
| 素材识别 | 封面、简短标题、商品、作者 | 素材ID、原视频链接、关联记录 |
| 使用情境 | 账户或店铺、平台投放状态 | 商品与计划的其他使用情境 |
| 经营表现 | 花费、归因成交、订单及上下文指标 | CTR、CVR、观看指标、基准详情 |
| 诊断 | 证据状态、主要问题、建议操作 | 内容结构、对比样本、修改要求 |

**分类与判断**

以“全部、需处理、观察中”等任务状态提供快捷筛选；阶段、风格、作者和商品作为独立条件。平台学习状态与产品自定义的成熟或衰退分类分别说明。内容结构评分不自动产生“优质核心”或“可放量”标签。

同一视频用于不同商品或计划时允许分情境查看，不强行给唯一好坏结论。商品卡单独标识，不显示视频首帧或观看率建议，也不把“-1”当用户可理解的名称。

**操作与验收**

默认可预览、查看诊断和选择参考；有权限的角色可创建改版任务。诊断筛选与库存浏览可切换且不丢失范围。未成熟素材说明复核条件，达到商家设置的测试预算边界时进入人工复核，不能无限等待出单。

# 8 疲劳与素材详情优化

**对应页面**

E03与D03。疲劳作为素材表现中的筛选结果，完整证据进入素材详情。

**问题与原因**

空状态的平均疲劳分0.0、风险花费0与“正常”给人已经检查过的错觉。有数据时出现“健康/学习”、点击率下降100%、建议改首帧同时存在的情况。底部技术式口径说明没有帮助用户理解为什么得出结论。

**新的诊断顺序**

先确认历史与当前都有有效观测，再对比表现是否下降；继续核查消耗分配、商品条件和平台状态是否变化；最后给出疑似原因及建议。跨素材低于平均值不等于同一素材发生疲劳，库存老旧或近期无消耗也不等于疲劳。

近期与基准使用不同天数时，金额和订单应按可比周期或日均口径比较，比率应使用正确分母聚合。页面展示具体日期与实际值，不只显示“近3天对比前8天”。当期尚未完整、数据回传未完成时说明限制。

**详情内容顺序**

1. 原视频与当前店铺、商品、计划、日期范围。
2. 当前判断与证据程度，例如“疑似点击环节下降，待核查”。
3. 当前与基准的实际数值、样本量、比较来源和变化。
4. 可能影响表现的业务变化，如价格、库存、促销、预算或流量分配，缺少数据时由运营确认。
5. 与原视频片段关联的内容观察，以及可尝试的改版要求。
6. 保留、创建改版任务或继续观察，并记录下次复核条件。

**诊断边界**

数据不足时只提供可观察的内容结构建议，不预测CTR、ROI、爆款概率或可挽回成交额。只有2秒或6秒观看指标时，不生成精确到每秒的流失归因。没有明显下降时不默认套用“商业转化衰减”。

**可执行的改版示例**

运营确认需要测试开头表达后，任务写为“保留商品、主体演示和优惠文案，仅调整前3秒的商品展示顺序，输出一个新版本”。具体时间段以原素材检查结果为准。这比同时要求换首帧、缩短视频、改CTA更便于执行和复盘。

# 9 投放中心与任务记录优化

**对应页面**

E06、E07。截图明确显示两个页面尚未开放，当前不能按已有完整闭环设计用户承诺。

**问题与原因**

入口位于主要页签中，点击后却只有“即将上线”。页面暴露PRD P0、接口、后端上线、独立授权等内部说明，商家难以判断自己缺少权限还是产品尚未提供能力。任务记录还与左侧已有任务模块重叠。

**当前版本调整**

从主路径隐藏未开放的投放中心和任务记录页签。旧链接进入时使用简短的“功能暂未开放”说明，提供“返回素材表现”，不要求用户反复授权来解决尚未上线的问题。

如果当前只能输出诊断报告或修改要求，就只显示这些真实可用操作。不要展示无法兑现的发布、调预算、关停按钮，也不展示不能执行的任务列表占位。

**后续任务承接**

| 任务阶段 | 用户需要看到 | 状态边界 |
| --- | --- | --- |
| 待确认 | 原素材、问题证据、建议改动 | 建议尚未成为制作要求。 |
| 待制作或制作中 | 负责人、商品资料、保留与替换项 | 不等于已经生成或可发布。 |
| 待验收 | 新版本、任务要求、检查结果 | 生成完成不等于可用。 |
| 待投放或已提交 | 采用版本、关联对象、提交结果 | 提交成功不等于正在投放。 |
| 观察与复盘 | 上线范围、时间、实际表现和结论 | 数据不足时继续观察，不标优化成功。 |

任务归入现有“任务”模块，详情保留来源商品、素材及诊断快照。从素材详情创建后可查看任务；任务返回素材时恢复原范围，避免同一工作生成多份断开的记录。

**执行权限**

数据读取授权、素材使用权限和投放操作权限分别识别。后续若提供发布、移除素材、调整预算等动作，应清楚写明实际作用对象与结果；具体动作按真实平台能力和工作空间角色开放，不能用统一“关停”覆盖所有对象。

# 10 数据源页面与账户管理

**对应页面**

E08及其与素材洞察的返回关系。保留“设置 → 数据源”管理入口，页面标题建议为“广告账户与数据连接”，更直接说明用途。

**问题与原因**

当前页面以平台卡片为主，TikTok只有较小的“连接”按钮。用户不清楚连接后还要选择账户、启用同步，以及哪些数据会可用。Facebook“即将支持”与当前可用平台并列，未能突出可完成的操作。

**未连接时的层级**

先展示已支持的平台、接入价值和明确连接按钮。对于从素材洞察进入的用户，直接聚焦 TikTok 接入流程。暂不支持的平台移入低优先级“后续支持”区域，不占主要操作位置。

**连接后的账户记录**

| 信息 | 用户用途 | 展示与操作规则 |
| --- | --- | --- |
| 平台及账户名称 | 确认接入对象 | 名称优先，ID用于辅助识别和复制。 |
| 所属店铺与报表范围 | 判断哪些业务可分析 | 仅显示实际可访问范围，缺口明确说明。 |
| 连接状态 | 判断是否需重新授权 | 已连接、需重连、权限待补充分别表达。 |
| 同步状态 | 判断数据是否正在更新 | 未开启、同步中、已更新、暂停、失败。 |
| 数据时间与覆盖期 | 判断分析是否及时 | 最近成功更新、可用起止日期和缺失区间。 |
| 可用操作 | 恢复或调整接入 | 开始同步、重试、补充授权、管理范围、查看洞察。 |

详细失败记录、历史任务和技术错误放在展开区或运营后台；用户优先看到可理解的原因与恢复动作。不要将连接成功、同步成功和广告正在投放压缩成同一个绿色状态。

**批量账户体验**

同一账户重复连接时引导管理已有连接，不新增重复记录。多个账户部分失败时逐项展示，保留正常数据。更换授权人或移交管理时保留可追溯关系，避免设计师需要单独连接同一个账户。

**暂停与断开**

“暂停数据同步”应说明只停止更新，不操作广告投放。“断开连接”与“删除历史数据”分开，操作前明确影响范围；断开后如何保留或清除历史数据遵循产品已公布的规则，不静默删除团队资料。

# 11 授权激励与运营支持

**800积分提示需要明确规则**

截图中的“完成广告账户授权，一次性获取800积分”可以保留为辅助激励，但主说明应突出数据分析价值。奖励不应掩盖权限、账户选择或同步未完成的状态。

**建议的展示方式**

主标题为“连接账户，查看素材表现”；辅助说明为“首次符合条件的授权可获800积分，查看规则”。若当前没有明确的资格、发放和重连规则，应先补齐规则再推广。

| 环节 | 建议规则 | 异常处理 |
| --- | --- | --- |
| 奖励资格 | 建议按工作空间首次有效授权发放一次，最终以正式活动规则为准。 | 新增账户、重连、重复回调不重复奖励。 |
| 触发时点 | 与“完成授权”的宣传条件一致，核验有效账户后处理。 | 如改为首次同步完成奖励，须同步修改活动文案。 |
| 数据同步 | 奖励状态与同步状态独立。 | 同步失败不显示为授权失败，积分发放不代表数据已就绪。 |
| 展示结果 | 发放成功、待处理、资格不符分别说明。 | 发放异常进入可查询记录，避免用户反复授权。 |

**运营后台需要支持的排查信息**

以工作空间、账户名称和用户可见状态定位问题，查看授权是否有效、同步是否启用、最近成功时间、失败类别和当前报表覆盖。记录用户从哪一个入口开始连接、在哪一步中断，以及是否恢复成功。

后台只对具备权限的人员展示必要信息。客服获得的是“账户无权限”“连接已失效”“同步未完成”等可解释原因，不将令牌、原始授权内容或技术报错直接展示给商家。

**帮助内容与物料准备**

准备一页接入说明，包含接入前需要的角色、如何选择正确账户、如何识别店铺范围、同步完成后能看到什么。准备各状态的文案与按钮清单、连接失败恢复说明、800积分活动规则，以及已脱敏的典型样例。能力限制由产品核验后写成明确说明，不把内部研发计划放入用户流程。

# 12 有数据状态的口径与诊断修正

本轮空状态改造应同时保留前轮有数据评审的结论，避免接入后仍遇到不可解释的指标与分类。

| 问题 | 原因与影响 | 修正规则 |
| --- | --- | --- |
| 同范围花费相同，点击和订单不同 | 用户无法判断是否统计错误。 | 对齐范围、日期和更新时间；区分字段缺失与真实0。 |
| 82或85分对应优质，但无有效消耗 | 内容结构与投放结果混用。 | 分开展示结构观察和投放证据，不输出未经验证的优质结论。 |
| 衰退素材占比极高 | 近期无记录可能被误当表现下滑。 | 先确认历史有效表现，再判断趋势；无数据独立分类。 |
| 仅1笔订单判为素材问题 | 相关性被解释为原因。 | 使用疑似问题，核查价格、库存、促销及流量变化。 |
| 预计影响显示精确金额 | 目标差额可能被包装成提升预测。 | 目标差额按差额命名；无可靠预测依据时不显示可挽回金额。 |
| 同商品基准来源不明 | 未成熟素材可能互相充当基准。 | 展示基准来源、样本量、日期；不足时停止比较。 |
| 不同天数直接比较总额 | 周期长度导致虚假的衰减。 | 使用可比周期或明确日均口径，比率按有效分母汇总。 |
| 多标签花费排行被当效果排行 | 同一素材可属于多个标签，跨商品也不可直接推断优劣。 | 注明不可直接相加，优先在同商品条件下复盘。 |

**GMV Max口径说明**

Product GMV Max会将活动运行期间所选商品的付费与自然订单纳入归因。因此，经营总览的归因成交与付费点击指标不能直接拼成同一种付费转化漏斗。此规则依据TikTok官方归因说明。[S1]

ROI与CPO需按平台口径结合成交贡献理解。单独的低ROI或高消耗不足以证明素材失败；产品应展示证据和业务情境，再提出待验证的改版方向。此建议与TikTok官方素材评价说明一致。[S2]

**数据范围提示**

页面用短文案说明“当前范围、可用时间、是否含自然归因、哪些指标未提供”。完整口径按需展开，避免将报表字段、计算参数或内部权重铺在主界面。

# 13 角色场景与任务交接

**场景一 新商家首次进入**

商家进入素材洞察，第一屏看到连接价值和主按钮。完成平台授权后选择需要分析的账户并开始同步。同步完成后进入有真实数据的经营总览；若当前周期没有记录，则直接查看最近有数据的周期。整个过程不需要自己找到设置中的开关。

**场景二 已连接账户但数据突然空了**

运营进入后发现单个账户连接失效。页面继续展示其他账户的有效数据，并明确失效账户未纳入当前汇总。点击“重新连接”完成恢复，回到原来的商品与日期范围，不重复建立账户记录。

**场景三 新素材消耗少且未出单**

素材详情展示已经发生的消耗和观测情况，说明当前证据不足。运营检查商品和投放条件，系统列出复核条件。达到测试预算边界时进入人工复核；在此之前不同时贴上健康、疲劳和建议关停标签。

**场景四 运营安排设计师改版**

运营从一个具体商品进入素材详情，核对数据与原视频，选择一个主要改版假设。任务包含原素材、问题证据、保留项、修改片段、商品资料、负责人和交付要求。设计师无需阅读全部经营报表，也不需要拥有账户授权权限。

**改版任务示例**

任务目标：验证更早出现商品能否改善开头的观看与点击表现。修改要求：根据原视频检查结果调整开头表达，保留商品、主体演示和优惠说明。交付要求：一个新版本及修改说明。复盘要求：上线后在相近业务条件下对比，证据不足时不宣布改版成功。

**角色分工**

| 角色 | 主要负责 | 不应被迫承担 |
| --- | --- | --- |
| 管理员或接入负责人 | 账户选择、授权、同步范围和异常恢复 | 逐条解释设计修改细节。 |
| 投手或运营 | 判断经营影响、确认诊断、安排测试和复盘 | 复制内部ID、解释技术报错。 |
| 设计师或剪辑师 | 查看原片、理解改动、交付版本 | 独立授权广告账户、猜测报表口径。 |
| 产品与客服 | 维护状态、文案、规则及恢复指引 | 将未上线功能解释为用户操作错误。 |

# 14 分阶段实施与效果衡量

**P0 接入与可信度**

完成场景内连接入口、账户选择与同步衔接、统一空状态、授权失效恢复；修正无数据时的正常和供给不足结论；修正0与缺失值、同范围报表不一致、低样本强诊断。旧数据和部分失败的展示规则同阶段落地。

**P1 导航与日常工作**

合并两套总览和两套素材列表，将疲劳放入筛选和详情；隐藏未上线页签；完善名称与封面、基准说明、问题队列与任务衔接。数据源管理支持单账户状态和直接返回洞察。

**P2 增强能力**

在基础数据和任务链路验证后，再增加明确标注的示例报告、创意复盘、批量任务操作，以及平台实际支持的投放动作。该阶段不能反过来阻塞基本接入和只读诊断。

| 衡量目标 | 事件与计算口径 | 观察重点 |
| --- | --- | --- |
| 用户找到接入入口 | 未接入用户进入洞察、点击连接 | 入口曝光到点击的转化，按入口区分。 |
| 接入流程完成 | 授权开始、返回、成功、取消、失败、账户选择完成 | 成功授权人数除以开始授权人数，排除重复回调。 |
| 数据实际可用 | 同步开始、首次完成、部分成功、失败、首次查看真实数据 | 同步完成与真实有记录分开，不能合并为接入成功。 |
| 首次获得分析价值 | 首次查看真实商品或素材详情、首次确认诊断 | 计算从进入洞察到首次有效查看的时间。 |
| 异常能够恢复 | 空状态曝光、恢复按钮点击、恢复完成 | 按状态统计，不把取消筛选当重新授权成功。 |
| 诊断进入制作 | 查看诊断、采纳或驳回、创建任务、交付版本、完成复盘 | 看采纳原因和闭环完成率，同时记录误判反馈。 |
| 持续使用 | 周内查看真实数据、查看详情或处理任务的去重用户 | 计算功能WAU与回访，授权页访问和示例浏览单独统计。 |

所有事件携带工作空间、入口、投放模式、当前范围、页面状态和数据时间等必要业务维度。示例数据、测试账户和重复授权回调单独标识，不计入真实分析激活。改善目标在上线前建立基线后设定，不编造固定提升比例。

# 15 最小验收清单

**账户接入与状态**

1. 未连接用户进入任何洞察入口，首屏均可点击连接，不需要自行查找设置。
2. 连接成功但未选账户时引导继续选择，不显示同步成功。
3. 用户确认范围并开始同步后，无需再次开启隐藏开关。
4. 用户取消授权可回原页，不自动反复弹出授权窗口。
5. 重复连接已有账户不生成重复记录；重复同步显示当前任务状态。
6. 同步失败有恢复按钮；已有数据继续显示并标明更新时间。
7. 多账户部分失败时，正常账户可用，汇总明确纳入和未纳入范围。
8. 无管理权限用户可获得管理员接入说明，不要求其个人重复授权。

**空状态与口径**

9. 未接入、同步中、筛选无结果、无投放记录、样本不足使用不同文案和操作。
10. 未取得有效数据时不显示正常、疲劳0分或供给不足警告。
11. 指标缺失不填0，除数为0时不显示错误ROI、CPO或衰减比例。
12. 当前日期无记录时可调整日期，且不误要求重新授权。
13. 清除局部筛选不改变账户、店铺和原有权限范围。
14. 库存、当前有消耗素材、可诊断素材和证据充分素材的数量有独立说明。
15. 同一范围的花费、订单等指标一致；不同范围有明确标注。
16. 行业基准、成熟素材基准和预计影响均能解释依据；缺少依据时停止展示结论。

**导航与任务**

17. 经营总览与素材表现各有唯一主入口，旧入口映射到新位置。
18. GMV Max与竞价广告按模式切换，筛选和口径同步变化。
19. 主导航不出现无法使用的投放中心或任务记录占位页。
20. 账户和素材以名称、封面识别，ID不作为唯一可读名称。
21. 疑似疲劳能够查看当前与基准实际值、日期和样本，不只有分数。
22. 商品卡不出现视频观看或换开头建议。
23. 继续观察有复核条件，且不计为需人工执行的待办数量。
24. 改版任务保存原素材、证据、修改要求和版本，能返回原分析范围。
25. 授权、同步、生成和提交成功不被表述为广告已投放或优化有效。
26. 800积分资格、触发、失败与重复处理符合已公布规则。

验收应至少覆盖新用户、已有历史数据用户、多账户部分异常用户、无管理权限设计师四类角色或状态组合，并使用真实脱敏数据核对关键口径。

# 16 后续原型范围与评审事项

**下一轮原型需要覆盖的页面状态**

| 原型组 | 必须表达的内容 |
| --- | --- |
| P01 首次进入素材洞察 | 接入价值、连接主按钮、权限说明、已有连接管理入口。 |
| P02 账户接入流程 | 授权前说明、账户选择、可用范围、开始同步、返回关系。 |
| P03 同步与恢复 | 首次同步、失败、历史数据、失效重连、部分成功。 |
| P04 经营总览 | 有数据、真实无记录、无异常、问题队列和统一筛选。 |
| P05 素材表现 | 库存与诊断范围、列表识别、证据状态、疲劳筛选。 |
| P06 素材详情 | 原视频、比较证据、内容观察、修改要求和任务入口。 |
| P07 数据源管理 | 未连接、账户列表、能力缺口、暂停与断开说明。 |
| P08 创意任务衔接 | 从诊断创建、制作交付、返回素材、复盘；仅呈现已计划落地能力。 |

**原型前需要锁定的业务规则**

产品确认当前账户与店铺数据的实际可访问范围、用户角色权限、可同步历史区间和更新频率；确认800积分活动资格及触发条件；确认暂停与断开后的历史数据规则；确认素材健康线与诊断证据规则；确认现有任务模块可承接到哪一步。未确认能力不出现在用户界面的确定性承诺中。

**建议评审顺序**

先确认菜单合并及状态矩阵，再评审首轮接入与返回路径，随后用有数据样本验证报表与诊断，最后确定任务衔接和原型范围。每个问题以可见行为和验收结果完成闭合，不仅修改一个按钮或一段提示语。
