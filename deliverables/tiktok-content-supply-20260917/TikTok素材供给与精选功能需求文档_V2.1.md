**TikTok素材供给与精选功能需求文档**

V2.1　2026年9月17日　面向产品、研发、数据与运营

本方案利用已有达人及视频数据，先交付经过核验的营销素材卡片、详情和收藏，再按实际需求补齐站内播放、下载及复刻。研发重点是有限候选的接入、审核发布、用户浏览和收藏；运营通过定向TikTok观察补充特色素材。全库视频识别不属于本期范围。

本版补齐完整达人字段的用途、明确的素材排除规则，以及找达人后形成合作候选的最小流程。整体供给能力与首期开发分开：账号策略主要为运营工作，夜间接入和精选展示属于P0；媒体转存能力及达人候选管理属于有条件开放的P1，不作为P0上线前置条件。

**1 产品范围与首期约定**

**1.1 用户目标**

客户进入素材页面，找到商品演示、使用场景、测评对比或营销创意，查看源视频并收藏；需要创作时，使用已经具备复刻能力的素材进入现有创作流程。主池允许真人及AI营销内容，小账号AI营销素材保留为特色内容；AI属性不明时不标为AI。纯娱乐短剧和无商品营销关联的个人动态不进入精选池。

**1.2 本期交付边界**

| 范围 | P0 首期交付 | P1 条件具备后交付 |
|---|---|---|
| 内容来源 | 现有数据有限预选、运营提交源链接、日批次及去重 | 补充新的国家和来源，按效果优化预选 |
| 运营工作台 | 在现有管理后台增加一个素材供给工作页，包含批次、审核和已发布记录 | 对有限候选增加辅助识别，提高人工效率 |
| 客户页面 | 复用发现中的UGC爆款入口，使用素材卡片、信息详情、查看源视频、收藏和作者简要信息 | 具备可播放媒体后接入原沉浸式视频布局 |
| 收藏页面 | 资产→我的收藏，查找、查看、取消收藏和访问源视频 | 对可用素材开放下载、一键复刻 |
| 达人功能 | 素材详情内查看作者简要资料及已精选作品 | 有明确需求后加入达人候选、导出及跟进 |
| 暂不建设 | 全量视频过滤、全量下载、完整达人广场及CRM、自动联系达人、自动广告投放 | 后续单独评审 |

P0与原大视频原型的差异是媒体能力：未获得可播放视频时不显示虚假的播放器。UGC入口不增加顶部搜索、筛选、刷新按钮；客户市场与类目由试点配置确定。页面副标题使用“每天发现值得参考的营销创意”，不把真人素材统一称为AI视频。

**1.3 角色与权限**

客户只能浏览对当前工作空间开放的已发布内容、访问有效源链接并管理自己的收藏。收藏及浏览记录归属于“当前工作空间内的当前用户”，同一用户切换工作空间分别记录；其他客户与运营不能查看个人收藏名单，运营只看汇总使用数据。素材供给池可供获准的工作空间共用，具体推荐仍匹配各工作空间的市场和类目。

运营可查看批次、提交候选、审核、发布和下线。管理员负责来源与每日数量配置；数据团队按约定提供候选及更新结果。客户不能访问未审内容和内部审核备注，普通运营不能修改采集配置。直接访问旧详情地址同样执行权限和素材可见性判断，不能绕过审核。首期复用现有身份权限，不新增独立账号体系。

**1.4 首期执行参数**

下表为本版建议默认值，供研发实现和试点测量；这些数值不是已经验证的运营最优值。数量可由管理员调整，变更从下一日批次生效，当日批次保留原配置。

| 参数 | 默认值与解释 |
|---|---|
| 市场与类目 | 客户主要销售国家及2个重点商品类目；以下用美国英语市场举例，上线前由业务填写实际国家和类目 |
| 日候选上限 | 整个试点供给工作区每天80条新入队的唯一视频，国家、类目及来源合计，不各自获得80条；按北京时间自然日统计 |
| 日发布目标 | 20条首次发布视频；目标不强制达成，缺少合格素材时少发布 |
| 审核预算 | 每日60分钟的运营工时预算，由运营执行并记录，不要求P0开发自动计时或强制中断 |
| 审核预算耗尽 | 运营暂停继续审核，保存当前结果，剩余内容顺延；不得自动通过。次日先处理仍符合条件的积压，可调低当日新增量 |
| 采集截止 | 每日北京时间06:00前交付当日候选批次；来源数据更新时间另行记录 |
| 审核发布时间 | 建议09:00开始审核、10:00完成首轮发布；仍未审核的素材继续不可见 |
| 内容时长 | 5–120秒，包含边界；超范围不进入常规精选，时长未知先待补充 |
| 发布时间 | 常规候选优先批次日和前29个自然日；更早内容须运营填写时效例外原因后才可审核通过 |
| 分发窗口 | 按首次发布进入共享池的北京时间计算，今天和前6个自然日 |

**2 TikTok账号与内容运营要求**

本节主要由运营执行，首期使用运营表格记录，无需开发养号系统或自动互动工具。

**2.1 账号配置与稳定性**

首期使用1个主观察账号和1个备用观察账号。每个账号记录目标国家、语言、重点类目、负责人、正常或异常状态、最后检查日期和备用安排。观察账号与平台客户账号是不同对象，观察账号发生异常不能影响客户登录和已有素材浏览。

使用受控设备及稳定网络，开启双重验证，保留恢复方式并检查登录设备。账号密码和恢复凭据放在团队现有安全管理渠道，不写入素材后台。出现登录异常、验证受阻或访问不稳定时暂停相关账号操作，负责人核查恢复，由其他正常来源和已有审核素材维持供给；备用账号提前维护，不能临时启用后假设推荐质量已经相同。

备用账号标记可接替前，由负责人确认最近两次维护均可正常访问、国家语言和内容方向符合要求、能够产出合格候选且恢复方式可用；不能正常发现相关内容的备用账号只能视为账号储备，不能计为稳定供给来源。此检查使用运营记录完成，不新增后台模块。

**2.2 搜索词与内容发现**

| 词组类型 | 首期示例 | 用途 |
|---|---|---|
| 商品与演示 | kitchen gadget demo、skincare product review | 寻找演示、测评及使用过程 |
| 问题与场景 | small space storage、travel packing | 找到生活场景和商品解决问题的表达 |
| 商业相关标签 | #TikTokShop、#ProductReview、对应商品类目标签 | 扩充候选来源，标签本身不作为带货事实证明 |
| AI营销方向 | AI product video、AI product demo | 补充AI表达方式，排除只有教学或娱乐、没有商品营销参考的内容 |

这些是待验证的种子词，不代表已经证实的高产关键词。运营每周保留有效词、移除无关结果过多的词；新国家使用对应语言重新准备，不只翻译标签字面。

日常路径为“定向搜索→查看相关作者→关注稳定来源→浏览推荐流→记录有效候选”。有价值的视频正常看完，分析需要时重看；无关内容及时跳过或反馈不感兴趣。收藏和关注依据实际参考价值，不设必须点赞或评论的数量任务。

**2.3 频率 时间与效果记录**

主账号每天2次，每次10–15分钟作为试验起点；备用账号每周维护2–3次。首周分别在目标国家当地白天和晚间的固定时段操作，记录相关内容数、浏览样本数、新候选数和耗时。每周选择有效产出更好的安排，不把短期差异直接解释为算法规律。

定向观察得到的链接由运营提交至候选来源，默认参加下一日批次。夜间采集是北京时间的交付安排，与观察账号应在何时使用分别管理。TikTok官方披露观看、跳过、互动、语言和位置等会影响推荐，但没有承诺固定停留秒数或晚间操作一定有效。

**2.4 地区扩充节奏**

首个国家连续运行至少两周后，每两周评估一次扩区；现有市场能在预算内稳定供给、已有客户需要新市场、且有人能审核对应语言时，每轮新增一个国家。建议顺序为客户主市场→一个东南亚目标国→一个南美目标国，按客户业务调整，不默认覆盖整个地区。

东南亚按实际目标选择一个国家，例如菲律宾、泰国或越南，并分别准备当地关键词及语言审核。南美葡语和西语分别规划，例如先验证巴西或一个客户已有业务的西语国家。每个新市场上线前先形成一批人工核验样本、配置工作空间市场、准备主备观察来源；新市场的数量和工时预算必须明确增加或重新分配，不把原80条额度默认为每国80条。现有市场供给受影响时暂停继续扩区。

**3 候选接入与每日批次**

**3.1 接入前必须核对的数据**

按数据团队提供的信息，目前每日更新千万级达人账号下的素材，存量视频为亿级，每个达人展示最新10条；这些规模为业务输入，接入前需核实可供本产品使用的具体范围。现有达人资料和视频索引可以直接复用为预选基础，但进入“精选营销素材”的单条视频仍需核验。当前未下载单视频，P0的默认观看方式是跳转源视频。

| 项目 | 核对结果如何影响功能 |
|---|---|
| 最新10条视频 | 区分页面展示限制与实际数据存储范围；没有更多历史时，不能承诺覆盖达人全部作品 |
| 视频级商业信息 | 确认广告、品牌合作或商品关联是否为可用字段；只有截图标签而无可用数据时，不能依赖它自动选入 |
| 标识与源链接 | 必须能识别同一源视频并访问来源；缺失时等待补充 |
| 时长与原发布日期 | 用于判断5–120秒及内容时效；缺失不能默认合格 |
| 历史数据快照 | 没有连续快照时只展示当前累计值，不计算增长速度 |
| 地区与语言 | 标明作者所在地、受众所在地、视频语言的各自口径，不互相替代 |
| 媒体可用性 | 区分只有封面与链接、可播放媒体、可下载文件；现有数据默认按仅源链接接入 |
| 更新交付 | 核对上游每日更新时间；06:00前只能拿到旧快照时，展示实际更新时间并标记该批次使用旧快照 |

**3.1.1 已有字段如何利用**

| 现有字段 | P0用途与展示位置 | 不应作出的推断 |
|---|---|---|
| 达人头像、名称、标识 | 素材卡片、详情与作者信息；标识用于关联该作者的精选作品 | 同名不等于同一个达人 |
| 性别 | 在作者信息中按已有可靠数据展示；P0不作为营销视频排除条件 | 不凭头像猜测，也不作为内容质量判定 |
| 行业标签、hashtag标签 | 数据预选及作者资料标签；运营可据此扩充搜索词 | 达人有商品标签不代表每条视频都在带货 |
| 语言、地区 | 作者资料与候选粗筛；发布前另确认视频适用市场 | 作者所在地不等于受众所在地，达人语言不等于每条视频语言 |
| 受众画像标签 | 作者资料折叠区域展示已有受众年龄、性别、地区等标签，辅助后续达人匹配 | 不作为该视频实际观看受众或商品购买者证明 |
| 最近10条视频的封面、标题、发布日期 | 用于小批候选预选；通过审核的单条进入精选，未审核视频不混入客户精选列表 | 最新10条不代表全部历史作品，也不保证全部营销相关 |
| 单视频播放、点赞、评论、收藏、分享等 | 素材详情按实际可用字段展示；来源口径及更新时间可在详情说明中查看 | 不代替单视频订单、GMV或广告投放效果 |
| 粉丝量 | 卡片及作者资料；准确小于10,000用于小账号AI精选归类 | 未知或模糊10K不能认定为万粉以下 |
| 平均播放、互动率 | 作者信息中展示已有数据及统计周期；辅助判断作者表现 | 不伪装为当前视频指标；周期或分母未知时暂不展示 |
| 最近发布视频的时间 | 候选作者活跃度判断及作者资料 | 不代替当前素材原发布日期 |
| 达人GMV预估、带货客单价 | 作者商业表现区域展示，保留估算标识、币种和统计时间；为后续合作候选提供参考 | 不分摊到某条视频，不承诺实际销量或合作结果 |
| 商品类目 | 预选作者和视频候选，辅助匹配客户商品 | 达人类目不直接覆盖每一条视频的类目，单视频类目由审核确认 |
| 佣金率 | 若有明确关联商品或计划、适用时间，放在对应关联项下展示；仅泛化字段且口径不明时隐藏 | 不把单商品佣金显示为该达人的统一合作报价 |

作者信息默认仅展示头像、名称、地区、语言、粉丝及已精选作品；受众与商业表现放在“更多资料”中，避免素材页堆满达人指标。各项信息按实际返回展示，不因字段存在于数据表就强制全部放到前台。平台收藏与源平台收藏数量分开；未知值不填0。

**3.2 预选规则**

数据团队优先使用已有视频级商业标识缩小候选，再按试点国家、语言、商品类目、近期发布筛选；没有商业标识时，以相关达人及标题、封面、标签作为预选线索。只输出受每日上限约束的候选，不要求先下载或识别全库视频。

候选优先级为：明确商品关联或商业标识的视频→具有商品演示、测评等线索的视频→运营主动发现的其他有价值视频。运营提交时可标记“优先核验”并填写原因，但仍占用当日候选额度且不得绕过审核。每个达人常规每日最多进入5条新候选，跨来源合计，防止单一账号占满；精选内容更丰富后再调节。

同一优先级先参考原发布时间，近期内容优先；发布时间相同时参考播放量降序，再以源视频标识确定稳定顺序。无互动数不按0参与比较，同时间段内排在有数据候选后。此排序只用于工作队列，不代表平台爆款排名。

去重先于计算80条额度。已经存在的视频只更新数据，不新增候选、不重复占额度；已发布内容不因刷新播放数重新审核。标题、视频内容或源身份发生实质变化时，转为人工复核；正在展示且存在内容变更风险的素材先下线。

新唯一候选成功进入待审核或待补充队列时占用额度；进入后即使不通过或被移除，当天不返还额度。接入失败且没有形成候选记录不占额，历史积压和复审不占新增额度但计入审核工时。运营超额提交时显示“已保存，等待下一批接入”，可在来源提交记录查看，不误报已经进入当日审核队列。

**3.3 运营工作页与批次反馈**

夜间处理建议从前一日23:00启动，归入次日批次，至次日06:00前交付；具体启动点与上游更新时间对齐。数据负责人在05:30前核对未完成来源和失败记录，交接可审核批次、实际数据更新时间及异常原因；运营09:00开始处理。P0复用现有排班和告警渠道，不新增消息系统。06:00后补齐的记录仍归原批次并标为迟到，不把交付时间改写为按时完成。

在现有管理后台增加“素材供给”工作页，使用“今日批次、待处理、已发布”三个视图，不新增三个独立业务模块。

批次视图展示日期、来源、配置上限、来源数据更新时间、开始及结束时间、接入新候选数、重复更新数、失败数和批次状态。状态为“未开始、处理中、已完成、部分完成、失败”。06:00仍有来源未完成时记为部分完成或失败，保留已成功的候选，展示原因和重试入口；不伪装已完成。

管理员可对失败来源重试。重试只补充当日未成功内容，保留已接入结果、顺序和已用额度，不重复创建整个批次。每日上限用尽时，新增链接留到下一批；重复更新仍可完成。单个观察账号异常只影响该来源。

审核通过与发布数分别统计。当天首次发布的素材计入新增，恢复下线素材和重复更新不算当日新增。

**4 素材审核 发布与下线**

**4.1 列表与审核详情**

运营待处理列表展示封面、标题、作者、原发布日期、时长、来源、地区/语言、商业线索、待补字段和状态。支持按状态、批次和来源查找，按源链接或视频标识定位；这些筛选只出现在后台，不增加到客户UGC页面。

点击一条打开审核详情，左侧为封面或可用视频，右侧为字段、商业线索、审核项、备注和操作。提供“查看源视频”，在新浏览器标签打开。审核员必须核验完整源视频，不能只看封面或标题通过；无法访问完整内容时使用待补充。

**4.2 通过条件与审核动作**

审核员先确认视频身份、时长和原发布日期，再确认营销相关性与内容安全。可接受内容包括商品演示、测评对比、使用场景、商品情节短剧及具有参考价值的商业创意。品牌曝光型作品标为“品牌营销参考”，明确商品关联的标为“商品营销参考”；这两个标签都不表示视频已经产生订单。

二次审核明确执行以下排除规则；这些是本产品入池口径，不表述为TikTok统一处罚规则：

| 排除类型 | 具体处理 |
|---|---|
| 涉黄或色情内容 | 不通过，不进入共享池；服饰或美妆的正常商品展示不因类目名称直接排除，须看完整内容判断 |
| 涉政内容 | 以政治人物、政治事件、政治宣传或争议为主要内容的不入池；避免仅凭单个词自动误杀 |
| 暴力血腥与明显危险内容 | 不通过；无法确认时待补充并由具备判断能力的人员复核 |
| 无营销关联的个人动态 | 纯自拍、聚会、旅行记录、日常聊天等若无商品展示或明确营销参考点，不通过；生活化商品场景可保留 |
| 非带货或非营销短剧 | 只有娱乐剧情、没有商品或品牌营销参考的不通过；带商品情节或明确营销表达的短剧按实际内容判断 |
| 明显欺诈、误导及违规商品内容 | 不通过；不确定的商品或宣传内容暂缓发布，不自动判定安全 |
| 重复搬运 | 同源视频更新已有记录；候选中确认的重复搬运不重复发布，保留更完整且可追溯的来源 |
| 无法正常理解或使用 | 视频严重损坏、黑屏、缺段、音画严重错位等导致不能判断创意时不通过；暂时访问失败先待补充 |
| 纯教学、教程或无商品AI奇观 | 对当前商品营销主池没有明确参考点时不通过；不因AI标签自动入池 |

审核必须覆盖完整候选视频，疑似风险内容不依赖封面、标题或关键词自动放行。已发布内容收到相关反馈后重新核验，确认不合格时执行下线规则。以上只对有限候选和反馈关联素材执行，不扫描亿级全量视频。

发布必需信息为：源视频标识、有效源链接、可展示封面、作者标识及可读名称、原发布日期、已核验时长、运营确认的适用市场、商品类目、营销类型与一句参考点。文案、头像、粉丝数和互动指标可缺失，按页面缺省规则展示。作者地区只用于粗筛，不直接当作视频销售市场；运营结合语言、商品及场景确认适用市场，无口播视频可标记“无口播”，不能擅填英语。记录字段核验人、核验时间及源链接最后确认有效的时间。

审核结论与操作如下：

| 操作 | 必填内容 | 操作结果 |
|---|---|---|
| 通过审核 | 已查看完整内容；身份与字段合格；营销相关；内容安全；视频类目与营销类型；一句参考点 | 进入已通过，仍不向客户展示 |
| 待补充 | 缺失项或无法确认原因，例如时长未知、源链接访问失败、语言无法审核 | 保留候选并移出可发布范围；补齐后回到待审核 |
| 不通过 | 原因：无关动态、非营销娱乐、风险内容、重复、时长不符、质量不合格或其他说明 | 保留内部记录，退出候选供给；重复采到不自动复活 |
| 发布 | 审核已通过、封面与基础字段齐备、源链接有效 | 进入共享池，首次发布时记录首次入池时间 |
| 下线 | 选择失效、内容风险、相关性误判、重复或其他说明 | 立即退出新分发；详情及收藏按下线原因处理 |

AI属性使用“AI、真人、无法确认”，只有确认后才标记。小账号AI精选同时要求AI已确认、粉丝数准确且小于10,000；10,000及以上、未知或模糊10K均不能归入。

候选超出近30天时，通过审核前必须填写“仍有参考价值”的例外原因。源发布时间晚于当前时间、负数指标或身份不一致，按待补充处理。空文案允许保留，不强制生成所谓源标题；页面使用“未提供文案”。

运营可以批量发布已通过素材，不能批量将未审素材直接通过。20条是整个供给工作区当天的首次发布目标，不是发布硬上限。发布时默认选择补足目标所需的已通过素材，运营可调整数量；确认框展示本次及当日合计，超过20条时提示超过目标但允许发布合格内容。未选择的已通过素材保留，跨日发布前必须再次确认源链接有效并更新核验时间。审核工时预算耗尽时保存当前结果并停止继续审，不影响已经发布的内容。

**4.3 状态及重新处理**

状态主线：待审核→已通过→已发布→已下线；待审核也可转待补充或不通过。待补充在补齐后回到待审核。不通过素材仅运营明确选择重新审核并填写原因后回到待审核。

已下线素材恢复前重新核验问题，必要时重新审核，随后才可恢复发布；保留首次入池时间，不冒充今日新内容。超过分发窗口的已发布素材退出默认推荐，但仍可出现在原收藏和来源关联中，不自动删除或标为失效。

客户在当前详情遇到素材刚下线时，显示“该素材暂不可用”，禁用不再允许的操作并提供返回或下一条。安全风险、内容违规下线时隐藏媒体和源链接，收藏只保留占位与取消收藏入口；单纯播放或链接失效时保留标题和作者等可用信息。运营内部备注不直接展示给客户。

P0候选源链接打不开时进入待补充；已发布内容经运营核验确认为删除、私密或持续不可访问时，以“源视频失效”下线，关闭外链入口并禁止新增收藏。一次用户反馈或临时网络失败不直接认定永久失效，运营需复核。所有已下线内容禁止新增收藏，已有收藏可保留或取消；恢复发布后再开放收藏。P1仅本地媒体失败而源链接仍正常时，可以回退至P0信息与源链接模式，不必下线整个素材。

**5 客户页面及收藏功能**

**5.1 素材列表**

客户从现有UGC爆款入口进入素材列表。P0采用卡片浏览，每批加载12条，底部“加载更多”接续当前队列；没有更多时显示“近7天精选已看完”，提供“查看新内容”“去我的收藏”“重看本轮精选”。查看新内容只检查已发布共享池，不触发额外采集。不增加顶部搜索、筛选、刷新、更新时间或今日精选条。

页面的市场和类目使用试点工作空间配置；一个用户进入的队列只包含匹配范围内已发布且可展示素材，不因供给不足自动混入其他国家或未审内容。

| 卡片内容 | 展示与操作规则 |
|---|---|
| 封面与时长 | 展示封面、真实时长和右上角收藏书签；无可播放媒体时不展示可点击播放的假控件 |
| 标题或文案 | 最多2行；列表内不撑开卡片，完整内容在详情查看 |
| 作者信息 | 头像、名称和粉丝数放同一行；名称过长截断，缺失头像用默认图 |
| 视频数据 | 播放量与原发布日期放同一行；缺失值显示“—”，点击详情查看其他互动 |
| 操作 | “查看”打开站内详情；“查看源视频”新开标签；书签收藏按钮独立响应，不同时触发详情 |

P0不展示下载、一键复刻按钮。后续仅在对应素材满足能力要求时出现，不用整页不可点击按钮制造能力已经可用的印象。

**5.2 详情弹窗**

点击封面或“查看”在当前页打开“素材详情”，背景保留原页面并遮罩。关闭按钮和Esc关闭弹窗，返回原卡片及滚动位置。源视频外跳后弹窗保持当前素材，不自动进入下一条。

P0左侧显示大封面与“查看源视频”入口，说明“前往TikTok观看”；不显示进度条、暂停、音量或全屏播放器控件。右侧上方放作者头像、名称、粉丝数，使用横线与发布日期、播放量区隔；互动数据分别展示点赞、评论、源平台收藏、分享，缺失为“—”。源平台数据只读，不与本产品收藏状态混用。

完整文案默认最多2行，超出出现“更多”，展开后出现“更少”；短文案不显示按钮。展开区域设最大高度并内部滚动，不挤出操作按钮。切换素材时恢复收起。作者信息不重复覆盖在封面左下角。

右侧操作沉底：P0为收藏或已收藏、查看源视频；后续媒体能力开放时加入下载、一键复刻。产品收藏使用与“我的收藏”一致的书签，源平台收藏数量使用五角星；源平台点赞、评论、收藏、分享图标不可被误认为可操作的社交按钮。文案统一“源视频”。

弹窗上下切换只沿当前来源列表的顺序：从UGC打开使用当前UGC队列，从收藏打开使用当前收藏搜索结果顺序。到首尾时相应按钮不可用，不切到其他来源或未匹配素材。

**5.3 展示记录及队列恢复**

用户首次进入时，按今日→昨日→近7天其余内容形成队列；各天内使用稳定的随机顺序，用户之间的记录独立。跨日同一源视频不重复创建。页面加载、预加载或下载封面本身不代表已展示。

本版将卡片封面成功加载、卡片至少50%进入视口连续1秒定义为一次有效展示，这是产品统计口径，不等于视频观看。弹窗成功展示也可记录展示，重复进入去重。分别记录“已展示”“已点击源视频”；只有后续站内播放器实际开始播放时才记录“已播放”，不推断外站完播。

刷新或重新进入时优先恢复当前浏览队列、位置和已加载批次；恢复当前队列允许用户回看已经展示的卡片。本轮跨越午夜仍可恢复，不因为日期改变强制重排。点击“加载更多”只追加尚未进入队列、符合当前7天窗口的合格内容，不重排已加载顺序；本轮中已加载但跨日超出7天的素材仅保留回看位置，不作为下一轮新推荐。

用户看完本轮后，选择“查看新内容”时才按当时日期生成新轮次，排除历史已展示素材；没有新内容时仍显示终点。主动“重看本轮精选”可以展示原队列，不清空历史记录。恢复位置对应素材已下线时，定位到本轮下一条可用素材，无剩余则显示终点，不恢复已下线媒体。

新增发布内容在当前队列未加载部分中补入，不跳走用户正在查看的素材。已下线项在下一次加载或切换时移除；当前详情中的下线情况按4.3处理。加载失败不记录展示，提示重试且保留位置。

**5.4 我的收藏**

“资产”下二级菜单顺序为“我的收藏、商品库、我的创意”。UGC和详情收藏成功后立即同步到我的收藏，同一用户同一素材只保存一份；按钮操作中防止重复点击，失败时恢复原状态并提示重试。

收藏页保留“搜索标题或作者”，默认按实际收藏先后倒序；不增加“UGC爆款”标签、数量横栏或“最近收藏”下拉，不显示收藏时间。每页12条，保留搜索、页码和滚动位置；无收藏时显示“还没有收藏素材”及“去发现素材”，搜索无结果时显示“没有匹配的收藏”及“清空搜索”。

卡片沿用作者与粉丝同一行、播放与发布日期同一行，按钮使用“查看”。点击后在收藏页上方打开同一详情弹窗。取消收藏只删除个人关系，其他人的收藏、共享视频和已创建创作项目保留；弹窗不突然关闭，按钮恢复“收藏”，关闭后刷新列表。重新收藏按新收藏时间排序。

收藏超过7天继续保留。视频失效时显示“视频暂不可用”，保留可用信息和取消收藏；源链接仍有效且无内容风险时允许查看源视频。内容风险下线按4.3隐藏媒体及源入口。

**5.5 作者信息与反馈**

在详情点击作者名称打开简要作者信息层，默认展示头像、名称、地区、语言、粉丝量及已精选作品，提供查看源主页；“更多资料”按3.1.1展开受众、表现和带货数据。未审核的个人近期作品不混入精选列表。达人预估GMV标明“预估”及时间范围；缺少口径则不展示，不推算单条视频成交。

详情提供低强调的“反馈”入口，原因仅设“内容不相关、源视频打不开、信息有误、其他”。提交后提示已收到，进入运营待处理记录并关联素材，不自动替用户取消收藏。运营核查后修正、下线或保留；用户举报是上线后的补充，不能替代上线前审核。

**5.6 达人广场的判断与最小合作流程**

建议首期保留作者详情作为素材的延伸，不仅因为已经有海量达人数据就新增独立达人广场。两条用户任务分别是“找素材做创作”和“找达人谈合作”；后者有持续客户需求时，才在发现下增加独立找达人入口。未经筛选的近期作品可以在明确标注的达人原作品页面展示，但不能冠以精选带货素材。

现有字段可以用于找达人，但独立入口至少需要下面的行动路径，否则只是数据查询页面：

发现素材或筛选达人→查看作者表现与作品→加入达人候选→关联拟合作商品并记录理由→查看有效联系渠道或导出名单→由用户自行联系→记录跟进与合作结果。

建议作为P1按以下最小范围实现，复用已有列表或任务能力，不同时建设寄样、合同和结算系统：

| 功能 | 用户操作与业务规则 |
|---|---|
| 加入候选 | 作者详情显示“加入达人候选”；选择拟合作商品或活动，填写匹配理由，重复加入同一工作空间的同一达人与商品组合不产生重复项 |
| 候选记录 | 保存达人、关联商品或活动、来源素材、创建人、负责人、匹配理由、状态和下次跟进日期；默认创建者负责。由当前工作空间成员按既有权限协作，区别于个人素材收藏 |
| 比较与导出 | 展示候选的地区语言、商品匹配、粉丝、平均播放及已有商业表现；缺失值为未知。允许导出选中的候选与跟进信息，用于团队内部讨论 |
| 联系入口 | 只有实际可用且允许展示的联系方式才出现复制或访问入口；没有联系方式时提供源主页。用户自行联系，P1不承诺站内发消息、批量邀约或对方一定可联系 |
| 跟进状态 | 待评估→待联系→已联系→有合作意向→已合作；任一未成交阶段可标记不适合或暂缓，需备注原因。状态由用户手动记录，不由访问源主页自动推断 |
| 已合作结果 | 用户填写实际合作方式、日期和结果说明；可附作品源链接。记录合作不自动生成真实GMV、回复记录、授权或付款结果 |

独立达人广场的启动条件为：现有客户持续提出找达人需求，候选与联系流程有人使用，且联系字段和团队跟进方式可用。若客户只消费素材，保留作者详情即可；如果人工精选预算暂时无法落实，可单独验证找达人服务，但不能把未经审核的达人近期作品直接替代营销精选供给。

**6 按需转存与后续能力**

P0保存可展示元数据、允许使用的封面及源链接。账号养号记录、达人全库和原媒体下载不作为P0客户浏览的前提。后续只对已精选且有客户使用需求的视频处理媒体，不全量下载。

| 媒体状态 | 进入条件 | 客户可用功能 |
|---|---|---|
| 仅源链接 | 已审核发布，只有封面及有效源链接 | 查看信息、查看源视频、收藏 |
| 获取处理中 | 运营发起有限素材的获取，展示和使用边界已确认 | 保留P0操作，不提前开放媒体按钮 |
| 待媒体校验 | 获取到文件，尚未完成身份和播放检查 | 保留P0操作，文件不直接向客户开放 |
| 媒体可用 | 与源视频一致，时长、完整性、画面和声音检查通过，内容复核通过 | 可开放站内播放；下载与复刻仍分别判断 |
| 获取失败或媒体失效 | 获取失败、播放不可用或后续文件失效 | 回退到仍然有效的P0能力，运营可重试；源视频也失效时退出新分发 |

媒体处理状态与审核发布状态分别管理：审核通过不等于有视频文件，有文件也不等于可发布。只有播放验证通过才使用既有大视频布局；作者信息在上、分隔线清晰、操作按钮沉底，文案保留2行更多/更少规则。

下载按钮仅在下载能力与使用条件均满足时出现，失败保留详情并提示重试，不影响收藏。一键复刻仅在参考视频可以被创作流程接受时开放；点击进入现有创作流程并带入参考视频，用户补充商品或其他必填项后手动提交，不因点击按钮直接生成或扣费。失败返回当前素材详情并说明可重试，不生成空项目冒充成功。

**8 底部落地计划**

以下为建议顺序，不将未核验接口和媒体能力写成确定工期。先完成数据验证，再按P0验收上线；P1作为独立增量。

| 阶段 | 具体交付 | 分工 | 进入下一阶段的条件 |
|---|---|---|---|
| 第1周前半 数据核验 | 50–100条样本、字段口径、最新10条限制、来源时效、去重标识、商业标签可用性及源访问验证 | 数据负责交付，运营核验内容，产品确认范围 | 明确有限候选来源与06:00交付范围，测得通过率和单条审核耗时 |
| 第1周后半 首批内容与流程 | 确认国家和2类目，形成50–100条已核验素材，准备主备账号和种子词；完成P0列表、状态、操作与权限评审 | 运营精选，产品定稿，研发拆分任务 | 有可展示的内容、明确规则和负责人，审核成本在预算内 |
| 第2阶段 P0开发与联调 | 有限接入与批次、后台审核发布、客户卡片和详情、收藏、反馈、去重和状态同步 | 数据接入，研发实现，运营参与联调 | A01–A24及A27–A28通过；仅源链接模式完整可用；实际开发排期由团队估算 |
| 第3阶段 小范围试用 | 3–5名客户试用，按每日20条目标运行两周，记录每日供给、相关性、链接有效性、人工成本、查看与收藏 | 产品收集客户反馈，运营维护，数据监测交付 | 问题有修复路径，合格上新与成本连续两周可控，客户能找到可用参考 |
| 第4阶段 媒体能力补齐 | 选客户真实需要的小批素材，验证获取、转存、二审、播放、下载和复刻；按素材能力开放按钮 | 数据与研发验证，运营校验，产品验收 | A25–A26及对应媒体链路通过；失败可回退到P0能力 |
| 后续扩区与达人能力 | 每两周评估，按客户需求新增一个国家及语言；有持续找人需求再按5.6补达人候选、导出和跟进 | 业务确定需求，运营提供语言能力，产品控制范围 | 现有供给稳定，新市场有客户、审核负责人和预算；达人功能通过A29–A30；不一次扩整片地区 |

每周只复盘四组结果：交付及时性与合格新增、内容相关性与源链接有效性、每条合格素材的人工及处理成本、客户查看源视频和收藏及创作意向。将观察账号浏览、素材审核和媒体处理工时分别记录，便于判断成本来自哪一环。
