# 素材详情｜统一样式与字段列表

日期：2026-09-04。范围：用户提供的四处素材详情，兼容 TTCC、MetaLib、TikTokLib；仅交付样式示例与字段规范，不修改业务代码。

## 1. 统一结论

**统一布局、字段分组、字段顺序和操作位置；不要求每个数据源展示相同数量的字段，更不能把不同含义的数据强行映射成同一指标。**

四处入口复用同一套弹窗。入口只影响主操作是否可用及点击后的去向，不影响素材字段名称和解释。

建议采用“公共信息＋来源可用字段”。不采用“一张表强塞所有指标”，避免大量空行；也不继续维护四套独立样式。

## 2. 弹窗样式

固定顺序：顶部标题 → 左侧预览／右侧详情 → 底部操作。

右侧固定顺序：**广告文案 → 表现数据 → 投放信息 → 素材信息**。某个可选字段隐藏后，其他字段仍按原顺序排列。弹窗不展示“数据来源”文案及对应来源名称；内部仍保留来源标识用于字段适配和去重。

| 区域 | 统一规则 |
|---|---|
| 顶部 | 固定“素材详情”标题；平台、视频/图片类型标签；右上角统一关闭按钮。长文案不占用弹窗标题位置 |
| 预览 | 左侧约44%，右侧约56%；素材完整等比展示，不裁切或拉伸。视频深色底，图片浅灰底，避免图片上下大片黑边 |
| 文案 | 原标题与正文去重展示；默认最多3行，可展开全文。不凭空生成商品标题，不默认翻译原文 |
| 表现数据 | 相同指标使用相同标签和卡片样式；数量随来源适配。最多一行4项，更多项目换行；不再只用没有标签的心形/星形图标 |
| 详情字段 | 标签左对齐、值右对齐；长文案和多值标签可换行，不能挤压标签或被截断而无法查看 |
| 底部 | 固定操作栏。左侧为可用的“查看落地页／查看广告原页”；右侧为“复制视频链接”和黑色主按钮“立即复刻”；图片素材对应显示“复制图片链接” |
| 复制对象 | 复制当前视频的实际媒体地址；图片素材复制当前图片地址。不是广告文案、封面、落地页或广告原页链接。素材ID旁独立复制ID图标，仍只复制ID |
| 滚动 | 桌面端右侧内容独立滚动，标题和底部按钮固定；关闭后保留原列表筛选、滚动位置，并停止视频播放 |

视觉建议：弹窗宽度不超过1120px，四周至少24px；高度不超过视口减48px；圆角16px，内容间距24px，常用间距4/8/12/16/24px。标题18px、正文14px、辅助文字12px；统一字重，不将整列值全部加粗。

颜色：白底；正文 `#111827`，辅助文字 `#6B7280`，分割线 `#E5E7EB`；主按钮 `#111111`＋白字；浅绿仅用于平台/品类等轻量标签。正常文本对比度目标至少4.5:1，选中/状态不只依赖颜色。

字体沿用现有系统字体；可选“系统中文字体＋Inter”，或“Noto Sans SC＋Arial”，不为四个入口单独更换字体。小屏改为单列，预览高度受限，正文滚动，操作栏不遮挡内容。

## 3. 公共字段与展示规则

“公共字段”指统一定义，不意味着缺值时必须显示一长串空行。

| 字段 | 展示规则 |
|---|---|
| 所属平台 | TikTok / Meta。Meta不能直接写成Facebook，除非数据确实只来自Facebook投放渠道 |
| 素材类型 | 视频 / 图片 / 其他。图片不出现播放进度、视频时长或播放器错误提示 |
| 预览地址、封面 | 展示有效素材；视频失败时保留封面和文字信息，提供重试；不能把封面当作视频已播放成功 |
| 广告文案 | 展示源文案；缺失显示“暂无文案”。展开/收起不影响其他区块；文案是否缺失不影响复制媒体链接 |
| 媒体链接 | 视频使用有效的`video_url`；图片使用有效的`image_url`。只用于预览与复制，不新增裸链接字段行；链接缺失时禁用对应复制按钮 |
| 广告主 | 展示来源提供的品牌、主页或广告主名称；可在提示中说明名称来源，不推断为付款方或法律实体。缺值显示“—” |
| 投放国家 | 中文国家名＋代码，例如“美国（US）”；多国用标签展开，不能只展示第一国或用注册地替代 |
| 投放渠道 | Meta使用来源提供的Facebook、Instagram等数组；与顶部平台信息完全重复时不必重复一行 |
| 投放状态 | 投放中 / 已停止 / 未知。未知用灰色标签；审核通过、已下载不等于投放中 |
| 日期 | 按含义显示“开始投放”“结束投放”“最近展示”或“广告库日期”，不能全部改名为开始投放 |
| 投放天数 | 仅有可靠累计投放天数时展示；“今天减首投时间”不是连续投放天数 |
| 商品品类 | 只展示可信商品分类；推断结果需标明“推断”。不得直接使用Meta主页类目或TikTok营销目标充当商品品类 |
| 主页类目 | Meta可单独显示，例如Clothing (Brand)。与商品品类分开命名，不放入相同语义的绿色商品标签 |
| 画幅 | 竖版 / 横版 / 方形；优先根据媒体宽高校验。不要与视频/图片类型混成“素材格式” |
| 分辨率 | 有可信宽高时显示像素尺寸；只有来源标注720P时保留原标注，不编造宽高；暂无元数据时可隐藏该行 |
| 时长 | 仅视频显示，例如95.2秒；播放器读到的可靠时长也可补充详情。未识别不补0秒，图片不显示这一行 |
| 行动号召 | 有值才展示，例如Shop now；不从广告目标推断CTA |
| 素材ID | 完整展示，可复制。内部需保留来源＋源ID，防止跨源同ID串数据；无需把内部源表名显示给用户 |
| 数据更新时间 | 有可靠时间才展示；无记录时不使用当前打开时间代替，不暗示状态为实时数据 |
| 原页、落地页链接 | 有有效对应链接才展示；原页链接与商品落地页链接是两个动作，不相互替代 |

日期默认展示YYYY-MM-DD，精确时间通过详情提示查看，避免仅某个入口显示完整秒数。数值使用统一中文缩写，如1.41万；查看提示或复制时可提供原始精确值，区间数据保留上下界。

## 4. 三数据源字段适配表

下表按用户提供的数据源说明制定；“无”表示当前说明未提供可直接使用的字段，不代表已重新连接数据库验数。

| 页面字段 | TTCC | MetaLib | TikTokLib |
|---|---|---|---|
| 广告文案 | `ad_title`；不依赖近乎全空的`highlight_text` | `title/body_text/caption`去重整理 | `title` |
| 广告主展示名称 | `brand_name` | `page_name`，对应主页名称 | `advertiser_name` |
| 商品品类 | `industry_cn_value` | 无可靠统一商品分类 | 无原生品类 |
| 主页类目 | 无 | `page_category` | 无 |
| 国家 | `country_code`数组 | `country` | `countries_arr`数组 |
| 投放渠道 | TikTok | `publisher_platform`数组 | TikTok |
| 投放状态 | 未知 | `is_active`明确true/false；缺值未知 | 未知；不用`audit_status`替代 |
| 开始投放 | `start_date`含义未核实前显示“广告库日期” | `start_date` | `first_shown_time` |
| 结束投放/最近展示 | 无 | `end_date`，按已确认的结束语义展示 | `last_shown_time`显示“最近展示”，不直接当结束投放 |
| 投放天数 | 无，隐藏 | `placement_days`，核实累计口径 | 无已确认连续投放天数，隐藏 |
| 素材类型 | 根据可靠媒体信息确认为视频；`material_format`仅表示画幅 | `material_type` | `material_type` |
| 画幅/分辨率 | `width/height/resolution`，修正标签反转 | 媒体元数据补充；未补则不编造 | 媒体元数据补充；未补则不编造 |
| 视频时长 | `duration`转数值并校验 | 来源未列出；可由视频元数据补充 | 来源未列出；可由视频元数据补充 |
| 视频链接（用于复制） | `url` | `obs_video_hd_url` | `url`，不直接使用`videos`内临时地址 |
| 图片链接（用于复制） | 无对应图片素材字段 | `obs_image_url`；有效的`original_image_url`可备用 | `image_urls`需解析并校验当前图片地址，不用`cover`冒充原图 |
| CTA | 无 | `cta_text/cta_type` | `call_to_action` |
| 落地页 | `landing_page_url` | `landing_page_url` | `external_url` |
| 素材ID | `id` | `ad_archive_id` | `id` |

### 表现数据：必须保持不同口径

| 指标 | TTCC | MetaLib | TikTokLib |
|---|---|---|---|
| 点赞 | `like` | `likes`；确认是素材点赞，而非主页/账号指标后展示 | 无，隐藏 |
| 评论 | `comment` | 无，隐藏，不补0 | 无，隐藏 |
| 分享 | `share` | 暂不使用`collation_count`冒充分享 | 无，隐藏 |
| 收藏 | 无已确认收藏数量字段，隐藏 | 无已确认收藏数量字段，隐藏 | 无，隐藏 |
| CTR | `ctr`，先确认数值单位和含义 | 无，隐藏 | 无，隐藏 |
| 消耗等级 | `cost`，按已确认枚举显示低/中/高；0不是$0 | 无，隐藏 | 无，隐藏 |
| 预估消耗 | 无金额，隐藏 | `estimate_spend`；保留预估标识与已确认币种；确认日/累计口径后明确标“预估日消耗/预估累计消耗” | 无，隐藏 |
| 触达人数 | 无，隐藏 | `total_reach`；明确数据统计范围 | 无已确认的统一实际触达口径，暂不强填 |
| 预估触达区间 | 无 | 仅可靠来源有值时显示 | `estimated_audience_lower/upper`须核验定义后使用，保留区间，不取上界冒充实际人数 |
| 目标人群规模 | 无 | 本次不新增 | `target_audience_size_lower/upper`仅作为可选定向信息，不放进表现数据冒充触达 |
| 播放量 | 当前无明确字段，不展示 | 当前无明确字段，不展示 | 当前无明确字段，不展示 |

**来源不支持的字段隐藏；来源支持但该条素材缺值或待确认时显示“—”；真实有效0才显示0。** 状态是例外：始终可表达“未知”，不隐藏未知状态来制造在投印象。

如果一个素材没有任何可用表现指标，表现区仅显示“暂无可用表现数据”，不展示一排0或—。金额、触达与互动并非同一统计窗口时要分别说明；没有明确口径就不暗示均为近14天数据或当前所选国家数据。

## 5. 统一操作与状态

- **立即复刻**：由当前入口权限、素材可访问性与现有复刻能力共同决定。可用时启用，不可用时灰置并提供具体原因；不因数据源不同而随意改变按钮样式。素材详情不会直接开始发布广告。
- 若某入口本来就是创作中的素材选择，主操作可由入口传入“使用此素材”，不再重复创建复刻任务；是否存在此入口以实际产品为准。
- **图片不是永久禁用复刻**：支持图片输入的链路可以启用；只有视频输入链路时才灰置。样式图中的灰置只演示不可用态，不代表已验证现网图片能力。
- **加载中**：预览和文字区域分别加载，不让整个弹窗空白。媒体失败保留已取得的详情；详情失败可重试，不展示上一条素材的信息。
- **关闭**：关闭按钮、Esc、遮罩关闭方式一致；打开时锁定背景滚动并约束焦点，关闭后焦点返回触发卡片。所有按钮支持键盘、可见焦点和可读名称。
- **复制链接**：视频点击“复制视频链接”，将有效视频地址写入剪贴板；图片点击“复制图片链接”，复制当前图片地址。链接缺失或已确认失效时禁用按钮并提示原因，不用封面、广告原页或落地页兜底。只复制用户有权访问的媒体地址，不包含后台凭证。
- **复制结果**：剪贴板写入成功后提示“视频链接已复制”或“图片链接已复制”；失败时提示重试，并提供对应链接的手动复制入口。素材ID复制仍独立处理，不复制整个弹窗。
