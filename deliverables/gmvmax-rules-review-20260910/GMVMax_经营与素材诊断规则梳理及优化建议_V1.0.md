# GMV Max 经营与素材诊断规则梳理及优化建议

版本：V1.0  
日期：2026-09-10  
依据：用户提供的四张规则截图，以及本次核对的 TikTok 官方说明。

本文区分三类内容：“现有规则”忠实整理截图；“待明确”表示截图未定义或存在歧义；“优化建议”是待评审的新方案。未读取生产代码，因此不能据此认定线上实际执行方式。

## 1. 总体判断

现有方案已经有一条清晰的业务链：用数据筛选素材 → 输出六类结果 → 选择修改方向 → 生成新素材 → 保存投放方案 → 后续复查。

主要缺口在判断依据和状态边界：
- 截图详细定义的是“商品 × 素材 × 国家 × 观察窗口”的素材规则，商品/计划层的独立经营诊断尚不完整。
- 样本成熟、测试预算、经营回报、内容问题、下一步动作混在一套分类里。
- 六类规则并未覆盖所有指标组合；优先级只能解决同时命中，无法解决完全不命中。
- ROI、CTR、CVR可以提示排查方向，不能单独证明内容问题的原因。
- 现有阈值属于产品自定规则，截图没有提供历史验证结果，不能称为官方标准或已验证最优阈值。

建议的总顺序：数据是否可用 → 是否达到人工预算复核条件 → 各指标证据是否充分 → 商品/计划经营判断 → 素材问题定位 → 运营确认一个主要动作 → 制作与复盘。

## 2. 现有指标口径

下文简写：R = ROI Index；T = CTR Index；C = CVR Index。

| 指标 | 当前计算方式 | 商家可理解的含义 |
| --- | --- | --- |
| 目标订单成本 | Target CPA = 预计 AOV ÷ Target ROI | 在给定客单价和目标回报下，对应的目标每单成本 |
| 回报达成指数 R | Actual ROI ÷ Target ROI | R=1表示达到目标，R=0.8表示相对目标低20% |
| 点击指数 T | Creative CTR ÷ Benchmark CTR | 素材点击率相对比较基准的水平 |
| 转化指数 C | Creative CVR ÷ Benchmark CVR | 素材转化率相对比较基准的水平 |
| 相对差 | (Index−1)×100% | 相对高低，不是百分点差 |
| 趋势 Trend | 近3日指标 ÷ 前7日指标 − 1 | 当前与历史的变化；指标类型、期间是否重叠及汇总方式待明确 |
| 样本充分 | (Active Time≥24h 且 Orders≥5) 或 Spend≥2×Target CPA | 达到时间与订单条件，或者达到消耗条件，即进入可诊断样本 |

### 当前基准规则

1. 同商品、同国家、近7日的成熟素材。
2. 排除当前被诊断素材。
3. 对比较素材计算去极值均值。
4. 少于5条时扩大到14日。
5. 仍不足时，回退到同账户、同品类。

仍需定义：去极值方法；CTR/CVR如何汇总；每条素材和整个基准需要多少曝光、点击及转化；回退同品类后是否保持国家与价格范围；回退仍不足时怎么办；“订单”是否与平台SKU订单保持一致。

### 当前口径中的关键区别

- ROI Index=0.8是“低于目标20%”，不能写成“ROI下降20个百分点”。
- Target ROI是经营目标，不天然等于盈亏平衡点。
- AOV、目标ROI、订单单位及币种必须配套。GMV Max使用SKU订单时，应采用对应单位的收入/订单口径，不能直接混用店铺整单客单价。
- 图4另提“48小时+订单≥5的判赢门槛”，与24小时的成熟门槛可能是不同阶段，但现有材料没有明确解释两者关系。

## 3. 六类结果：现有规则还原

截图中的优先级为：待观察 → 建议关停 → 需换新 → 可放量 → 需迭代 → 稳定投放。每条素材最终输出一个结果、一个主动作。

以下“并且”按条目共同生效整理；原图没有括号的复杂或分支，另列待明确项，不默认已确认。

| 结果 | 当前触发条件 | 当前含义与动作 |
| --- | --- | --- |
| 待观察 | 任一满足：①时长不足24h且消耗不足2倍目标CPA；②订单不足5且消耗不足2倍目标CPA；③关键指标延迟/缺失；④素材刚加入素材池 | 证据未成熟，不参加其余五类判断；继续观察，必要时重试同步 |
| 建议关停 | 样本充分；R<0.70；Spend≥2×目标CPA；连续2个诊断窗口低于止损线；并且T<0.80或C<0.80 | 进入止损确认；确认后移出素材池，保留历史记录 |
| 需换新 | 样本充分；基础区间为0.70≤R<0.90；T<0.80且C<0.80；另有“历史曾达标、ROI较历史稳定期下降≥30%”分支；连续2个窗口未恢复 | 局部修改可能不足，选择新方向并生成素材 |
| 可放量 | 样本充分；R≥1.15；订单数≥max(10，同商品素材订单均值)；近3日ROI Trend≥−10% | 保留原素材，生成衍生版本；创建放量方案或生成爆款变体 |
| 需迭代 | 样本充分且R≥0.90；分支为①T<0.80且C≥0.90，改Hook；②T≥0.90且C<0.80，改卖点/Offer；③某单项近3日Trend≤−20%，其他指标正常 | 保留主要内容，一次选择一类修改方向，生成变体 |
| 稳定投放 | 样本充分；1.00≤R<1.15；T≥0.90且C≥0.90；近3日ROI与CTR波动均<15% | 保持投放，安排复查 |

### 必须明确的逻辑歧义

1. “历史曾达标、ROI下降≥30%”是否可以独立触发换新，还是仍必须满足0.70≤R<0.90？两种理解会影响当前仍达标素材的分类。
2. 迭代的“单项趋势下降”分支是否同样受R≥0.90限制？
3. “其他指标正常”“波动<15%”“止损线”“历史稳定期”“刚加入素材池”没有明确计算或时长定义。
4. “连续2个窗口”是两个完整、不同的数据窗口，还是用户刷新两次？需明确不能用同一批数据重复计数。
5. “低于止损线”与R<0.70是否是同一条件？若不同，截图缺少止损线的来源。
6. 可放量订单门槛中的“同商品素材订单均值”需要定义统计周期、比较素材范围，以及是否排除自身。

| 结果 | 当前步骤 | 当前末步操作 |
| --- | --- | --- |
| 可放量 | 数据诊断 → 选择衍生参考 → 生成新素材 → 投放配置 | 保存方案并前往投放中心 |
| 需迭代 | 数据诊断 → 定位迭代变量 → 生成新素材 → 投放配置 | 保存方案并前往投放中心 |
| 需换新 | 数据诊断 → 选择新方向 → 生成新素材 → 投放配置 | 保存方案并前往投放中心 |
| 稳定投放 | 数据诊断 → 复查与越界规则 → 已加入监控 | 创建72h复查任务 |
| 待观察 | 数据诊断 → 样本与数据质量 → 达标后自动重诊断 | 继续观察；次操作为重试数据同步 |
| 建议关停 | 数据诊断 → 止损确认 → 移出素材池 | 确认关停，二次确认 |

图1还提到：可放量24h后回看、需迭代48h后比较、需换新上线后观察72h、稳定投放72h复查。这些应定义为复查时间点，不能自动等同于样本成熟或测试胜出。

“建议关停”中的操作对象，以及移出素材池对平台实际投放的影响，需要按真实能力确认。“方案保存”“素材生成”“投放提交”“平台实际投放”分别展示。

## 5. 五类制作方向：现有规则整理

| 制作方向 | 当前主要观察指标 | 改什么 | 当前锁定内容 | 候选示例 |
| --- | --- | --- | --- | --- |
| 换Hook | CTR | 前3秒的开场话术、首帧画面和节奏整体替换 | 正文、卖点、Offer、CTA | 结果先出、痛点冲突、价格利益、反常识、转场揭晓、奇观吸睛 |
| 换出镜达人 | CTR | 换人不换脚本，检查人与商品的匹配 | 脚本结构、卖点、Offer | 素人自拍、专业背书、达人实测 |
| 换场景 | CTR | 改环境与画面氛围 | 人物、台词、Offer | 浴室日常、通勤补妆、户外自然光 |
| 换卖点与证明 | CVR | 主打卖点及其证据形式 | Hook、人物、Offer | 效果先行、实测对比、权威证言、UGC合集 |
| 换Offer与CTA呈现 | CVR | 结尾利益表达与行动指令，不改实际优惠 | Hook、正文、价格 | 限时折扣、买赠组合、库存告急、路径演示 |

当前限制：可放量的衍生版本只选择前三类之一；需换新不使用这张局部变量表，改为重新选择方向。

保留五类作为设计师工作分类是可行的，但“单变量”建议改称“一次只改一类创意因素”。一个Hook同时变话术、首帧和节奏，只能评估这套开场方案的整体表现，不能区分三个元素各自的作用。

## 6. 当前问题、原因和优化方向

### P0：影响判断可信度或可能造成错误经营动作

| 问题 | 原因与具体影响 | 优化方向 |
| --- | --- | --- |
| 用素材ROI直接判断素材优劣或关停 | GMV Max口径包含付费与自然归因；低ROI可能伴随更高的成交贡献 | 先看商品/计划的经营表现，再结合视频归因成交、订单、付费点击/转化和内容证据判断；不把任一单指标当完整结论 |
| 把低于目标写成亏损，把达标写成能赚 | 目标ROI不是利润线，截图没有毛利、履约、退款等成本依据 | 用“高于/低于目标”表达；只有明确利润口径时才表达盈利或亏损 |
| 消耗达到2倍目标CPA即样本充分 | 消耗门槛代表风险暴露，不保证有足够曝光、点击、订单或回传时间 | 分开“指标可判断条件”和“预算人工复核条件” |
| 一个Sample用于全部指标 | CTR、CVR、ROI的有效分母与稳定性不同 | 每个指标单独标识可用性、样本和不确定性；允许部分诊断 |
| 阈值组合存在未覆盖区域 | 六类条件不是完整分区，且没有兜底 | 增加“需人工复核/结论不足”兜底，覆盖每种输入组合，不默认归为健康或稳定 |
| 高优先级观察可能遮挡风险 | 关键数据缺失时都进入观察，但已知有效消耗可能已达商家的预算上限 | 保留数据问题提示，同时创建预算人工复核提示；不自动停投，也不无限等待 |
| CTR低直接改Hook，CVR低直接改卖点 | 指标是信号，不是因果定位；流量、价格、库存、商品页、运费都可能影响结果 | 先核查业务条件，再结合可用观看数据和具体视频片段形成修改假设 |
| 业务单位混用 | GMV Max的Orders是SKU订单，AOV可能来自店铺整单；CVR也可能误用总归因订单/付费点击 | 明确字段含义与分母，使用平台付费转化口径计算对应CVR，不能混造漏斗 |

### P1：影响稳定性、可解释性和制作效率

| 问题 | 原因与具体影响 | 优化方向 |
| --- | --- | --- |
| AND/OR作用范围不清 | 同一历史下滑条件可能被实现为不同分支 | 为每类规则定义基础条件、任一分支、排除条件、边界值及兜底 |
| “近3日/前7日”可能比较总量 | 不同长度的总量会产生结构性下降 | GMV、订单、花费用日均或等长周期；ROI/CTR/CVR先按各周期有效分子分母汇总再比较 |
| “波动<15%”未定义 | 不清楚是极差、日变化还是其他波动口径 | 固定一种业务可理解的定义并展示基期及有效天数 |
| 连续窗口和历史稳定期未定义 | 同一批数据重复评估可能被当成持续恶化，稳定期也可能被随意选取 | 定义完整数据窗口与复查频率，同一窗口只记一次；预先固定历史稳定期选取规则 |
| 相对基准可能失真 | 五条素材并不等于证据充分；简单平均不同样本量的CTR/CVR可能误导 | 在可比范围内按有效分子分母汇总，同时显示素材数、曝光、点击、转化及分布 |
| 回退同品类仍作强判断 | 商品价格、受众和场景差异可能大于创意差异 | 标注基准层级和可比程度，弱可比基准只提示观察方向，不触发关停或放量强建议 |
| 阈值附近来回跳状态 | 0.89和0.91、1.14和1.16可能只是正常波动 | 引入进入与退出缓冲区及持续性条件，幅度需用历史样本验证 |
| 24h/48h/72h混同成熟和判赢 | 固定时长无法保证各素材有足够测试机会 | 分别定义接入时间、实际投放时长、复查时间和证据成熟条件 |
| 可放量与生成衍生版本混为一体 | 增加原素材投入和测试新素材是两件事，新版本没有继承原版本成绩 | 分开“经营放量测试”和“创意衍生”；新版本单独积累证据 |
| 标称单变量，实际改变多个因素 | “专业背书”不只是换人，“卖点与证明”同时调整观点与证据 | 以五类制作方向组织工作，每次写清假设与实际变化，不声称识别了单一因果 |
| 稳定投放要求重复确认监控 | 结果页写自动复查，末步又要求创建72h任务 | 首次确认复查规则，后续自动沿用；避免重复任务 |
| 测试结束只比较ROI或48h结果 | 新旧版本测试时长、预算、流量分配与商品条件可能不同 | 使用可比条件；自然分发差异较大时标为观察性对比，不宣称A/B因果胜出 |

### 三个明确的规则空档示例

下列假设数据可用、样本满足当前门槛，且未触发趋势下降或历史下滑分支。

| 输入 | 为什么未被覆盖 |
| --- | --- |
| R=0.95，T=1.00，C=1.00，趋势平稳 | 未达到稳定投放的R≥1.00；又没有触发迭代的局部弱项；其他类别也不满足 |
| R=1.20，Orders=8，实际投放≥24h，T/C均正常 | 不足放量的至少10单要求；R又高于稳定区间；未触发其他问题 |
| R=0.65，T=1.00，C=1.00，趋势平稳 | 低于关停回报线，但不满足CTR或CVR低于0.80；不在换新、迭代或稳定区间 |

相反，R=1.20、订单充分、T=0.70、C=1.00、趋势平稳时，可能同时满足放量和迭代。目前按优先级只显示放量，点击弱项会被隐藏。应保留完整证据标签，同时由运营确认一个主要动作。

### 两个计算例子

1. 假设预计AOV=30美元、目标ROI=2，目标CPA=15美元。某素材实际投放2小时，花费30美元、0订单，已满足当前“样本充分”的消耗分支。这只能说明需要关注测试投入，不能证明每项指标已经足够稳定。
2. 若每天都是10单，近3日30单、前7日70单，直接比较总量会得到−57.1%，但日均订单完全没有下降。必须先明确Trend的聚合方式。

CTR基准也类似：10次曝光1次点击为10%，10000次曝光100次点击为1%；简单平均为5.5%，而同口径合并后为101÷10010≈1.01%。两者回答不同问题；素材分布可看中位数，整体流量点击率应按分子分母汇总，不能混用。

## 7. 建议的新规则框架

### 7.1 固定诊断对象与数据范围

每次判断明确：店铺/账户、投放计划、商品、国家、素材、日期、更新时间、目标ROI来源。

同一视频出现在不同商品或计划中应分情境判断。目标ROI、价格或优惠发生变化时记录变化时间，不能拿变化后的目标重新解释全部历史成绩。

数据按指标分为：可用、同步中、未提供、不适用。真实0保留为0；分母为0时不生成指数。某个观看指标缺失不妨碍查看其他有效经营数据，但不能据此判断开头流失。

### 7.2 分开“可判断”和“需控制投入”

| 规则层 | 回答的问题 | 建议行为 |
| --- | --- | --- |
| 数据有效性 | 当前数据有没有同步完整、口径是否正确？ | 修复或标明缺口，展示仍可用的数据 |
| 指标证据 | 有多少曝光、点击、订单和有效投放时间，是否足以支持该项判断？ | 按指标决定可比较、仅观察或不判断 |
| 预算复核 | 是否达到商家事先确认的测试预算边界？ | 无论是否已出够订单，都提醒运营复核投入 |
| 经营表现 | 商品/计划的成交、目标回报与投入是否匹配？ | 判断是否继续当前测试、调整计划或核查商品条件 |
| 创意证据 | 哪个具体内容环节值得尝试修改？ | 提出有视频证据的假设，交给运营确认 |

2倍目标CPA可以作为待校准的人工复核参考，不能继续充当所有指标的成熟证明。达到预算复核条件也不自动证明素材失败。

### 7.3 先做经营排查，再进入创意修改

下表是排查路径，不是直接因果结论。

| 观测信号 | 先检查什么 | 什么时候进入素材修改 |
| --- | --- | --- |
| 成交下降，花费也下降，ROI相对稳定 | 投放资格、计划设置、流量分配、商品库存 | 有足够素材层证据时再修改内容 |
| ROI下降，但成交与订单增加 | 是否为经营可接受的增量与成本变化，是否超预算 | 不能仅因ROI下降移除高成交贡献素材 |
| CTR下降，CVR相对稳定 | 流量变化、开场观看表现及商品展示 | 视频检查支持开场问题时，测试Hook、达人或场景 |
| CTR相对稳定，CVR下降 | 价格、优惠、库存、运费、商品页及点击人群 | 排除或明确这些变化后，再测试卖点、证明或CTA表达 |
| 观看、点击、转化持续下降 | 同商品其他素材是否也下降，是否有共同业务变化 | 业务条件可比且现有表达持续失效时，考虑新方向 |

### 7.4 六类结果保留，但改为运营可确认的建议

不建议现在直接更换一组未经验证的“精准阈值”。先改决策结构，再用历史数据校准原有0.70、0.80、0.90、1.15等参考线。

| 结果 | 优化后的含义与必要依据 | 主动作 |
| --- | --- | --- |
| 待观察 | 当前证据不足；明确缺什么及何时复核。若同时达到预算边界，另提示人工复核 | 查看观察条件 |
| 稳定投放 | 当前范围达成经营要求，没有证据充分的持续恶化 | 保持当前方案 |
| 可放量 | 改为“具备放量测试条件”：已有成交贡献与相对稳定表现，预算、库存等条件可支持测试 | 人工确认放量测试方案 |
| 需迭代 | 有一个值得验证的主要局部问题，并能提出清楚的改版要求；不强制必须R≥0.90才能修改 | 确认一类修改方向 |
| 需换新 | 持续走弱且业务环境可比，局部修改不足或不适用；低CTR/CVR只提供线索 | 确认新的表达方向 |
| 建议关停 | 建议改称“建议暂停测试”；因实际测试投入、回报、成交贡献及运营风险选择暂停，并明确作用对象 | 人工复核并确认实际动作 |

补充两种非业务结论：
- 数据异常：同步、权限或口径问题，提供修复动作。
- 需人工复核：规则未覆盖、基准不可比、多个结论冲突或原因无法区分；展示证据，不强行归入稳定/换新。

保留“一个主动作”，但允许显示多个观察标签。例如“经营表现较好；点击低于同商品基准”，不会因为主动作是放量测试就隐藏点击问题。自动建议不能代替运营对风险动作的确认。

### 7.5 新基准与趋势规则

1. 优先使用同商品、同国家、相近投放情境下的有效样本，排除被诊断素材。
2. 将素材数与曝光、点击、转化分母一起作为基准可用条件；只满足“5条素材”不够。
3. 近7日不足可扩大到14日，但标明基期变化；跨重大促销、改价或断货时需拆分。
4. 回退同账户同品类时显著标为弱可比参考；不用于强放量或关停结论。
5. CTR基准按有效点击/曝光汇总；CVR按同口径付费转化/点击汇总。需要观察“典型素材”时另展示中位数及分布。
6. ROI按各期累计归因成交/累计花费计算后比较，不能直接平均每日ROI；总量指标使用日均或等长周期。
7. 选择已完成且回传达到可用条件的日期，避免把今天未结束的数据与完整历史日比较。
8. 连续窗口只计不同、完整的数据窗口。若采用相互重叠的滚动窗口，只能解释为持续性观察，不能说有两份独立证据。
9. 明确进入/退出状态的缓冲和复查条件，用历史回放校准，不在截图基础上编造统一可靠阈值。

## 8. 五类制作方向的优化

| 方向 | 更合理的主要观察点 | 给设计师的要求 |
| --- | --- | --- |
| Hook | 可用的早段观看数据、点击及视频内容观察 | 把开场视为一个方案包；写清新的开场表达，锁定正文、商品、优惠 |
| 出镜达人 | 人物可信度、与商品匹配、观看/点击/转化变化 | 真正测试换人时保持脚本与证据不变；换专业背书属于额外内容变化 |
| 场景 | 使用场景匹配和表达清晰度 | 场景候选按商品生成，不强制所有品类用浴室或补妆场景 |
| 卖点与证明 | 卖点是否清晰、证据是否充分，以及相关转化观察 | 明确改主张、改证据还是二者一起改，记录实际变化 |
| Offer与CTA呈现 | 优惠理解、行动路径和相关转化观察 | 锁定真实价格、折扣和赠品条件；库存紧张、限时优惠及背书须有实际依据 |

每个改版任务至少包含：来源商品与素材、观察窗口、问题证据、主要假设、修改范围、保留内容、目标观察指标、负责人、交付版本及复核条件。

新版本不继承旧版本的“可放量”标签。48h/72h可以提醒查看，但胜出判断取决于证据与可比条件。没有受控测试时，只描述相同或相近条件下的观察结果。

## 9. 运营与设计师场景

### 场景一：新素材很快花到测试预算边界

2小时花到30美元、0订单。当前规则会认为样本充分。优化后显示“已达到本轮测试投入复核条件；订单证据仍不足”。运营检查回传与商品条件，再决定暂停、继续或调整；不直接让设计师重做整条视频。

### 场景二：点击变差，但点击后的成交表现保持

素材点击低于同商品基准，CVR相对稳定。先确认可比流量和样本，再检查前段视频。若发现商品出现较晚，可提出“保留主体演示、卖点和优惠，只测试商品更早出现的一版开场”。结果只验证这套开场方案，不宣称已经证明首帧或节奏是唯一原因。

### 场景三：ROI下降，但成交贡献提高

运营先判断订单和成交增量是否符合当前经营目标、预算与库存约束；不因R越过某条线就立刻移除素材。可同时保留当前成交贡献素材，并安排低风险衍生测试。

### 场景四：多个素材同时转化下降

先检查商品价格、优惠、库存、运费和商品页。若发生共同业务变化，优先修复经营条件，避免对所有视频生成相同的“改卖点/CTA”任务。

## 10. 建议落地顺序与最小验收

### 第一批：修正会导致误判的规则

- 区分经营达标、盈利、素材质量，不把三者混写。
- 将消耗复核与样本成熟拆开。
- 写清AND/OR与边界，补充数据异常及需人工复核兜底。
- 确认订单、CVR、AOV的同口径关系，区分付费指标与总归因指标。
- 暂停/移出等操作按真实对象和能力命名，并保留人工确认。

### 第二批：提高稳定性与可解释性

- 固定基准、趋势、持续窗口及状态缓冲规则。
- 将24h/48h/72h定义为复查点，不作为胜出承诺。
- 在详情里展示当前值、参考值、分母、期间、缺口、业务变化和主要假设。

### 第三批：形成可复盘的创作链

- 统一五类制作方向与保留项。
- 新旧版本和实际改动建立关联。
- 回传表现后复核，区分样本不足、观察改善、持续改善和结论不明。

### 最小验收案例

1. 关键指标未提供不会被填0，也不会因此判定亏损或疲劳。
2. 2小时、0订单、消耗达到2倍目标CPA不会被解释为全部指标样本成熟。
3. R=0.95且T/C正常等未命中情况进入明确兜底。
4. 同时满足放量与点击弱项时能查看两个证据，主动作可由运营确认。
5. 原有条件在0.70、0.80、0.90、1.00、1.15和等于各阈值时有确定结果；缺失与零分母另测。
6. 基准样本不足或回退同品类时明确降低判断强度。
7. 近3日和前7日总量不会直接制造虚假下降。
8. 同一窗口重复刷新不会计为两个恶化窗口。
9. 新素材、旧素材具有独立观察时间与成绩。
10. 无毛利和成本口径时不输出“已经能赚”“继续亏损”。
11. 修改Hook不会同时偷偷改变价格或正文卖点。
12. 方案保存或生成完成不展示为已投放，暂停建议不展示为已执行。

## 11. 官方口径核对与证据边界

以下仅说明平台指标的含义，不为本文自定义阈值背书。核对日期为2026-09-10。

- Product GMV Max在活动运行期间对所选商品的付费与自然订单进行归因，因此经营ROI不能直接视为某条视频的纯付费效果。[官方归因说明](https://ads.tiktok.com/resources/help/article/about-attribution-for-gmv-max?lang=en)
