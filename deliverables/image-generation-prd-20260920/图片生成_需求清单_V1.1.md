# 创意生成新增图片生成｜需求清单 V1.1

日期：2026-09-20  
适用页面：创意助手 / 创意生成、资产库 / 我的创意、我的任务。  
依据：用户提供的图一至图四及本次明确要求。本文为产品需求与原型方案，不代表功能已上线或模型已接入。

## 1. 需求背景

当前创意生成以视频为主。电商用户还需要制作商品展示图、广告图片与同一商品的多版素材。本次在现有创意生成入口增加图片生成，并补齐多结果生成、媒体类型识别、资产筛选与任务筛选，让图片和视频在同一流程内生成、查看和管理。

交付范围：三个页面的功能规则、图片模型参数、生成数量、积分规则及三个页面原型及图片详情弹窗示例。沿用现有白色圆角卡片、浅灰底色与浅绿色选中样式。

## 2. 需求清单

### 2.1 功能清单

| 编号 | 页面 / 模块 | 需求 | 具体规则 / 验收要点 |
|---|---|---|---|
| R01 | 创意生成：生成类型 | 在 Seedance 2.0 模型选择器前增加生成类型下拉 | 选项为「视频生成」「图片生成」；首次进入默认「视频生成」。这是创意生成内的模式切换，不新增一级页签。 |
| R02 | 创意生成：切换模式 | 根据类型展示对应的模型和参数 | 视频模式沿用现有视频模型与时长、比例、声音、Hook 模板等能力；图片模式展示图片模型、分辨率、生成数量，并隐藏视频专属的时长、声音、Hook 模板。 |
| R03 | 创意生成：图片模型 | 提供图四中的三个模型名称 | 「Wan3.0」「GPT Image 2」「GPT Image 2.5」。原型按原表保留名称；Wan3.0 的真实图片模型及接入能力尚待供应商确认，不能将其视为已核实的官方型号。 |
| R04 | 创意生成：图片分辨率 | 提供 1K、2K、4K 三档 | 按图四作为产品目标配置，默认 1K；选择分辨率后同步更新单张和本次总积分。供应商未实际支持的组合不可提交，并展示不可用原因。 |
| R05 | 创意生成：生成数量 | 视频和图片都增加数量选择 | 视频为「1条、2条、3条」；图片为「1张、2张、3张、4张」。两个模式首次默认数量均为 1。切换后单位和数量范围必须一起变化。 |
| R06 | 创意生成：草稿与参考素材 | 同一会话内分别保留两个模式的创作设置 | 分别保存描述、模型、分辨率和数量，视频另保存现有视频参数；切回时恢复该模式上次草稿。商品图、数字人人像可按对应模型支持范围用作图片参考；视频或音频素材不自动进入图片请求。 |
| R07 | 创意生成：提交与积分 | 提交前展示总数量和总积分 | 按钮明确显示「生成 N 张 / N 条 · X 积分」，旁边说明单价计算，如「8积分/张 × 3张」。切换模型、分辨率、数量或视频时长后立即重算。 |
| R08 | 创意生成：提交校验 | 保留现有生成前校验，并补齐数量、模型能力与余额校验 | 无有效创意内容、引用素材未就绪、模型不可用、参数不支持或余额不足时不能提交，并给出具体原因；请求受理前防止重复点击。 |
| R09 | 生成历史 / 最近任务 | 每个生成结果增加媒体标签 | 视频结果展示视频图标＋「视频」；图片结果展示图片图标＋「图片」。标签位置统一、文字始终可见；视频可保留时长，图片不显示播放按钮或视频时长。 |
| R10 | 多结果生成 | 一次提交创建一个任务，包含 N 个结果 | N 个结果共用提交时的创意描述、模型及参数，各自生成。任务聚合进度；生成历史展示独立结果卡，资产库按成功结果逐条入库，避免一次生成多张却只入库一张。 |
| R11 | 资产库 / 创意生成 | 增加媒体类型筛选 | 在现有页签下、素材网格上方增加「全部、视频、图片」，默认「全部」；与现有名称搜索共同生效。其它页签不使用这组媒体筛选。 |
| R12 | 资产库：卡片与预览 | 混排结果可快速识别和打开 | 卡片统一展示「视频 / 图片」标签；点击视频沿用视频预览，点击图片打开详情弹窗，左侧展示图片，右侧回显生成时的完整提示词和参数；保留现有下载等动作，并使用正确媒体文件。 |
| R13 | 我的任务：二级类型 | 在原任务类型筛选框右侧增加二级筛选 | 选项「全部类型、视频、图片」，默认「全部类型」。从左到右为：搜索、任务类型、生成类型、刷新。 |
| R14 | 我的任务：筛选联动 | 明确二级筛选的适用范围 | 一级为「全部任务」或「创意生成」时二级可用；「全部任务＋图片」只显示图片生成任务。一级切换为报告、分析或脚本时，二级置为「全部类型」并禁用，避免非生成任务被错误隐藏。 |
| R15 | 我的任务：任务识别与进度 | 生成任务展示媒体、数量及进度 | 保留「创意生成」任务分类，新增「图片 / 视频」媒体标识与「4张 / 2条」数量。进行中展示「已完成 2/4」，结束后区分全部成功、部分成功、全部失败。 |
| R16 | 空态与异常 | 图片和视频均有明确状态 | 无结果时显示「暂无图片资产 / 暂无视频资产」等匹配筛选的空态；加载失败可重试刷新，保留筛选条件；生成失败不作为可用资产入库。 |

### 2.2 图片参数与视频数量

| 生成类型 | 模型名称（前台） | 分辨率 | 生成数量 | 初始设置 |
|---|---|---|---|---|
| 视频生成 | 沿用现有视频模型，图一为 Seedance 2.0 | 沿用现有可用档位 | 1条、2条、3条 | 默认视频生成、1条；图一示例为 720P / 15s / 9:16 |
| 图片生成 | Wan3.0 | 1K、2K、4K（目标配置，待接入核实） | 1张、2张、3张、4张 | 图片首次默认 Wan3.0 / 1K / 1张（暂定）；实际未开通时选择首个可用模型 |
| 图片生成 | GPT Image 2 | 1K、2K、4K | 1张、2张、3张、4张 | 切换模型时保留仍受支持的分辨率和数量 |
| 图片生成 | GPT Image 2.5 | 1K、2K、4K | 1张、2张、3张、4张 | 前台统一为一个模型选项，不展示或要求用户选择 Sunburst / Flare |

本次图片参数区只新增模型、分辨率和数量选择。图片 quality 档位、供应商通道等不增加为用户操作项，但上线前必须绑定到确定的供应商规格，避免同一售价下实际输出配置不一致。

分辨率为产品展示档位，不直接等同于固定像素尺寸。各模型的实际宽高与比例应单独明确；未确认实际规格前，不将 4K 直接承诺为 4096×4096 方图。原型使用常见商品方图作布局占位，不作为某模型某分辨率的实测输出。

### 2.3 多结果与扣费规则（本次产品方案）

1. 点击生成后，保留该次提交的类型、模型、分辨率、数量、单价和总价；后续价格调整不改变该任务的报价。
2. 一次提交为一个任务，N 为结果数量，不要求供应商必须一次返回 N 个结果。我的任务聚合显示，资产库按成功结果拆开显示。
3. 状态分为排队中、生成中、已完成、部分成功、生成失败。存在未结束结果时继续显示生成中；全部结果结束后才确定最终状态。
4. 本方案按提交总价预扣，成功结果按该次报价结算，失败结果退回对应积分。例：GPT Image 2 2K 生成4张预扣32积分，成功3张、失败1张，最终24积分，退回8积分。
5. 重试失败结果需作为新一次生成，展示本次数量与积分后由用户触发；不得自动无限重试或重复扣费。若当前产品没有独立重试入口，可在原生成入口重新提交。
6. 生成历史与资产库只展示可用的成功结果；任务详情保留失败原因、成功数量和退回积分。旧视频记录补充「视频」标识，未知类型不得直接归为图片。

### 2.4 筛选与结果口径

| 页面 | 筛选默认值 | 数量统计单位 | 刷新 / 切换规则 |
|---|---|---|---|
| 资产库 / 创意生成 | 全部 | 成功的独立资产数；一次生成4张成功则为4项 | 筛选与名称搜索取交集；改变筛选回到第一页；无结果展示筛选空态 |
| 我的任务 | 全部任务＋全部类型 | 提交任务数；一次生成4张仍为1个任务 | 一级、二级、搜索取交集；改变任一筛选回到第一页；刷新保留筛选 |
| 最近任务 / 生成历史 | 保持现有列表逻辑 | 每张图 / 每条视频分别标记；属于同一提交的结果可显示同一任务编号 | 成功结果同步呈现；本次不额外增加新的历史筛选器 |

### 2.6 图片详情弹窗（本次新增）

| 项目 | 展示与交互规则 |
|---|---|
| 打开入口 | 从创意生成历史或资产库点击图片结果，打开统一的「图片生成」详情弹窗；左侧图片预览，右侧提示词与参数，参考本次提供的视频详情布局。 |
| 图片预览 | 完整展示当前单张图片，按比例缩放、不裁切；图片不展示播放按钮、视频时长或声音控件。 |
| 提示词回显 | 展示该图片所属生成任务提交时的完整提示词，保留换行、段落和参考素材标记；只读，长内容可滚动查看，不以省略号替代全文。 |
| 参数回显 | 至少展示模型、分辨率、本次生成数量。模型显示 Wan3.0、GPT Image 2 或 GPT Image 2.5；GPT Image 2.5 不展示 Sunburst / Flare。图片无视频时长、声音、Hook 参数。 |
| 数量含义 | 数量字段使用「本次生成：N张」，指该任务提交时的目标数量，不是成功数量，也不是当前预览图片数。例：提交4张、成功3张，详情仍回显「本次生成：4张」。 |
| 记录一致性 | 提示词与参数来自生成时的记录，不读取用户当前编辑器草稿或当前模型默认值；后续改提示词、切模型、调价格不改变历史详情。可辅助展示原任务编号。 |
| 参考素材 | 有参考素材时展示生成时使用的缩略图和名称；无素材时隐藏该区。素材失效时保留名称并提示不可预览。 |
| 历史缺失数据 | 原记录未保存的提示词或参数显示「未记录」，不得使用现有默认值补齐，也不得根据图片猜测。 |
| 再生成与下载 | 沿用现有底部动作。「调整提示词再生成」回到图片生成并预填可用的原提示词、模型、分辨率、数量和参考素材，不自动提交或扣分；原配置不可用时提示重新选择。「下载」下载当前图片原文件。 |
| 关闭与返回 | 关闭按钮、Esc 或点击遮罩关闭弹窗；保留来源页面的筛选和列表位置。 |
