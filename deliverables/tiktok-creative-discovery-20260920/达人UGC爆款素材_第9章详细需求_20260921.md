# 9. 详细需求

本章补充带货精选、素材详情、我的收藏、创意分析及创意衔接的页面和交互要求，不重复需求背景、数据模型等已完成章节。界面以本次提供的图1至图7及历史最终确认要求为准；下文「创意分析」指从素材详情点击「分析」进入的素材分析流程。

原型用于演示状态：下载3秒后切换为分析或拆解。正式功能必须依据真实任务状态切换，不能将3秒作为实际下载完成条件。文中补齐的重复点击、失败重试和任务恢复规则用于研发评审；具体计费、服务超时阈值等沿用现有能力，不在本章新增约定。

## 9.1 带货精选

### 9.1.1 页面入口与默认展示

1. 入口为「发现 → 带货精选」，位于「灵感发现」下方、「AIGC爆款」上方，不新增一级菜单。
2. 页面标题为「带货精选」，副标题为「发现TikTok上与你的商品相关的热门达人带货创意视频」，右上方保留TikTok平台标识。
3. 默认条件为地区「全球」、达人分类「全部」、商品品类「全部」；粉丝量、播放量、点赞数、时长和AI视频均不限，日期为空。
4. 默认按播放量从高到低排序，每页10条。宽屏桌面按图1展示一行5张卡片，满10条时为两行；较窄窗口减少列数，保持竖版封面和可读文字。
5. 列表展示当前用户可见、已发布且可浏览的素材。源视频已确认不可用的素材不继续出现在带货精选正常列表中，已收藏记录按9.3保留。
6. 不展示英文标题眉题、关键词搜索栏、独立「更多筛选」入口、列表上方重复素材总数。保留地区行中的「搜索国家」，它只用于选择地区，不搜索素材标题、商品或作者。
7. 首次加载显示卡片加载状态；加载失败显示失败提示与重试入口，不把加载失败当作「暂无素材」。

### 9.1.2 筛选区结构与组合规则

筛选区从上到下为「地区」「达人」「商品」「视频」四行，行标签不附加「分类」二字。「过滤条件」在筛选区下方展示，素材列表位于其后。

| 筛选行 | 展示内容 | 交互规则 |
| --- | --- | --- |
| 地区 | 全球、热门地区标签、搜索国家 | 单选；热门地区与搜索结果共用一个地区条件，不能同时选中两个地区 |
| 达人 | 达人粉丝量下拉、全部、达人一级分类 | 粉丝量与达人分类为两个独立条件，可同时生效；粉丝量下拉位于「全部」之前 |
| 商品 | 全部、商品一级品类 | 单选，使用当前视频关联商品的品类，与达人分类分开 |
| 视频 | 播放量、点赞数、时长、AI视频、起止日期 | 各项单选或日期范围，可组合使用；排序下拉放在本行最右侧 |

- 同一维度单选，不同维度取交集。例如选择「美国＋服装与时尚＋女装与内衣＋1万粉以下」，结果须同时符合这些条件。
- 选择标签、下拉选项或有效日期后直接生效，不再增加「应用筛选」按钮。
- 更换筛选条件后回到第1页，保留其他已选条件及当前排序。
- 选择「全球」「全部」或下拉「不限」，仅清除对应维度的限制。
- 达人分类和商品品类默认只展示一行；超出时在行尾显示「展开」，展开后显示全部并变为「收起」。一行能容纳时不显示展开按钮。
- 展开、收起不改变已选条件；即使选中项被收起，仍在「过滤条件」中显示，不能因折叠而失效。
- 地区标签正常排列，空间不足可换行，不套用达人和商品的展开规则。

### 9.1.3 地区与国家搜索

**热门地区顺序：**全球、美国、墨西哥、巴西、越南、泰国、菲律宾、马来西亚、印尼、新加坡、日本、英国、西班牙、德国、意大利、法国、希腊、比利时、捷克、波兰、葡萄牙、奥地利、匈牙利、荷兰、爱尔兰。

1. 热门地区后方增加输入框，占位文案为「搜索国家」。删除搜索图标及「（A–Z）」文案。
2. 搜索范围覆盖全部国家/地区，不局限于热门地区。当前原型使用249个国家/地区条目，正式使用统一的完整地区字典。
3. 点击输入框可展开国家列表；输入后根据关键词过滤，支持中文名称、英文名称及两位地区代码，忽略前后空格和英文大小写。
4. 搜索结果按英文国家名称A–Z排列，但界面只显示中文名称，不展示英文对照列。
5. 输入关键词只改变候选国家列表，不立即改变素材结果；选中具体国家后关闭候选列表，应用该地区条件并回到第1页。
6. 选中非热门地区后，输入框及过滤条件显示该地区中文名称；选择热门地区或「全球」时，替换或清除原地区条件，国家搜索框恢复「搜索国家」。
7. 清空正在输入的关键词只恢复全部候选国家，不自动清除已经应用的地区。清除地区通过「全球」或移除地区条件标签完成。
8. 查不到国家时提示「未找到匹配的国家」；国家存在但没有匹配视频时，显示素材列表空态，不能自动切换为美国或其他热门地区。
9. 「地区」采用作者所属地区口径，不代表广告投放地区、观众地区或商品销售市场。

### 9.1.5 下拉筛选、日期与边界

| 项目 | 选项 | 区间规则 |
| --- | --- | --- |
| 达人粉丝量 | 不限、1万以下、1万至10万、10万及以上 | 分别为小于10,000；大于等于10,000且小于100,000；大于等于100,000 |
| 播放量 | 不限、10万以下、10万至100万、100万及以上 | 分别为小于100,000；大于等于100,000且小于1,000,000；大于等于1,000,000 |
| 点赞数 | 不限、1千以下、1千至1万、1万及以上 | 分别为小于1,000；大于等于1,000且小于10,000；大于等于10,000 |
| 时长 | 不限、15秒以内、15至30秒、超过30秒 | 第一档包含15秒；第二档大于15秒且包含30秒；第三档大于30秒 |
| AI视频 | 不限、AI生成 | 默认不限；选中AI生成仅返回有明确AI生成标识的素材 |
| 日期 | 开始日期、结束日期 | 按视频原始发布日期；起止当天均包含，允许只选择开始或结束日期 |

- 区间判断使用原始数值，不使用「1万」「10万」等缩写后的显示值。未知值在不限状态下可出现，但不能进入指定数值区间；真实0按实际区间处理。
- AI视频筛选删除「非AI」「混合内容」「未确认」。删除选项不等于将相关素材重标为AI生成；未有可靠标识的素材不能凭封面风格或粉丝量判定。
- 不再提供是否带货、是否投流、新视频、评论数、转发数、内容类型等额外筛选。
- 开始日期晚于结束日期时，提示「开始日期不能晚于结束日期」，不应用错误范围，保留上一次有效条件。日期按当前用户时区理解。
- 所有下拉采用统一的白色圆角浮层，具有细边框、轻阴影、悬停背景与绿色选中态，不使用系统原生下拉菜单的外观。
- 点击选项后关闭下拉；点击外部或按Esc关闭但不修改选中值。支持键盘选择，浮层不被筛选容器或折叠区域裁切。

### 9.1.6 已选条件与排序

**过滤条件：**没有条件时显示「暂无筛选条件」；有条件时逐项显示地区、分类、粉丝量、视频条件和日期标签。点击单项移除只清除该条件；「清空筛选」恢复全部不限并回到第1页，保留当前排序。无匹配素材时保留条件，并提供清空入口，不自动放宽筛选。

**排序：**下拉固定放在「视频」行最右侧，不再占用列表上方独立一行，删除「精选顺序」。

| 排序项 | 规则 |
| --- | --- |
| 播放量从高到低 | 默认排序，按本条视频的播放量降序 |
| GMV从高到低 | 按本条视频的预估GMV降序 |
| 销量从高到低 | 按本条视频的预估销量降序 |
| 互动率从高到低 | 仅按统一口径的有效视频互动率降序 |
| 最新发布 | 按视频原始发布时间降序，不使用素材入库或收藏时间 |

排序对全部符合条件的素材生效，再按页展示，不能只重排当前页。更换排序回到第1页；数值缺失的素材排在有效值之后，真实0排在缺失值之前，相同值保持稳定顺序。GMV参与比较前须具备一致的币种和统计周期，不能直接将不同币种的数字混排。

### 9.1.7 素材卡片

| 位置 | 展示内容 | 要求 |
| --- | --- | --- |
| 主体 | 竖版视频封面 | 按9:16封面区域展示；优先真实视频封面，缺失时使用可用商品图或统一占位；不出现「示意封面」文案 |
| 封面右上 | 收藏书签 | 未收藏为空心，已收藏为绿色选中态；点击只改变收藏，不打开详情 |
| 书签下方 | 播放量、点赞数及图标 | 沿右侧纵向排列，只读展示；点赞图标不触发本站点赞或TikTok点赞 |
| 左下角 | 关联商品缩略图 | 有关联商品时显示，缺失时隐藏；点击进入当前素材详情 |
| 底部统计条 | 预估销量、预估GMV | 放在商品缩略图右侧，分别判断是否有值；任一缺失时只隐藏该项，两项均缺失时隐藏统计条 |
| 右下角 | 视频时长 | 展示为分:秒；有预估统计条时上移避让，无统计条时贴近底部，不能与GMV或销量重叠 |
| 封面下方 | 视频标题 | 一行展示，超长省略；悬停可查看完整标题，点击打开详情 |

- 点击封面、标题或商品缩略图打开9.2的同一素材详情弹窗，不直接进入分析或复刻。
- 封面卡片不再叠加作者、粉丝量、互动率、地区、发布日期，以及独立「查看详情」「查看原视频」按钮；详细信息放到弹窗内。
- 没有关联商品时，商品缩略图和商品带货预估条均隐藏。缺失值不能用0替代；实际预估销量为0或GMV为0时正常显示。
- 预估销量、预估GMV必须来自当前视频对应的带货数据，与详情页一致。不能使用作者近30天GMV、商品店铺总销量替代，也不能按播放量或商品价格猜测。
- 数量可按万、亿缩写；金额保留币种；悬停可提供完整数值和统计说明。数据来源、周期、币种及更新时间沿用已定义的数据模型，不能因为界面精简就丢失统计口径。

### 9.1.8 分页与空态

1. 采用分页，不使用「加载更多」或无限滚动。底部显示总条数、每页条数、上一页、页码、下一页、当前页/总页数。
2. 默认及最小每页10条，可选10、20、50条，删除5条选项。实际不足10条时展示实际数量，不复制素材补满。
3. 原型样本补充至10条用于展示两行；这不代表正式列表最多只有10条，也不代表我的收藏自动增加10条。
4. 首页禁用上一页、末页禁用下一页；页码较多时保留首尾页和当前页相邻页，中间显示省略号。
5. 修改筛选、排序或每页条数后回到第1页。翻页后滚动至列表可见起点，不要求用户先手动滚回列表。
6. 无匹配结果显示「没有找到符合条件的素材」及清空筛选入口，不显示无意义的分页控件。
7. 关闭详情回到列表时保留筛选、排序、页码和浏览位置。

## 9.2 素材详情

### 9.2.1 打开、布局与关闭

1. 带货精选、我的收藏均打开同一套详情弹窗，内容、操作及数据口径保持一致，带入实际点击的素材，不能固定展示默认样本。
2. 采用居中弹窗和背景遮罩，左侧视频、右侧信息。桌面参考尺寸为960×720，整体4:3，左侧405×720、比例9:16；窗口不足时适配，保证视频和底部操作可用。
3. 右侧内容较长时可滚动，底部操作区保持可见。外层列表在弹窗打开时不随之滚动。
4. 弹窗外侧顶部展示「观看 TikTok 视频前，请确保已开启外网访问。」，不覆盖视频画面。
5. 点击右上关闭、遮罩空白或按Esc关闭。关闭后保留原列表条件和位置，并停止弹窗中的播放，避免关闭后仍有声音。

### 9.2.2 左侧视频区域

- 展示当前素材视频及播放封面，包含播放/暂停、进度、已播时间/总时长、音量及全屏控件；底部不增加播放设置按钮。
- 参照TikTok播放器样式展示作者名称与账号、TikTok标识，以及视频本身的点赞、评论、分享数和标题。这些数据必须对应当前素材。
- 删除「播放器原型」等可见文案、示意封面提示、重复播放入口和重复观看说明；正式页面不使用静态图片假装视频已经播放。
- 初次打开不强制有声自动播放，由用户操作播放。加载中、播放失败应在视频区内反馈，不遮挡右侧信息。
- 站内播放失败但源链接仍有效时，保留「打开原视频」作为查看入口；单次加载失败不能直接认定为视频已删除。

### 9.2.3 右侧信息顺序与字段

从上到下依次为：视频标题 → 视频表现 → 带货预估 → 作者信息 → 关联商品 → 操作按钮。

| 模块 | 字段与规则 |
| --- | --- |
| 视频标题 | 展示完整标题，可换行；不附加素材编号、编辑状态和平台/品类眉题 |
| 视频表现 | 横向展示播放量、点赞、评论、分享、互动率五项，只展示当前视频数据 |
| 互动率 | 统一口径为（点赞＋评论＋分享）÷播放量×100%，保留两位小数；可通过悬停查看口径，不再占用说明段落。播放量为0、必要数据缺失或统计口径不一致时显示「—」 |
| 带货预估 | 两张并排浅色卡片，左「预估 GMV」、右「预估销量」；缺失时显示「暂无数据」，实际0正常显示；与封面上的数据一致 |
| 作者信息 | 头像、名称、账号、粉丝量；只读展示，不显示进入箭头，不打开作者二级详情，页面中不重复设置作者模块 |
| 关联商品 | 商品缩略图、商品名称、价格、「查看商品」；价格保留币种，不附加「USD · 来源价格」说明 |

补充规则：

1. 普通指标未知显示「—」，不能伪装为0；头像或商品图片缺失时使用统一占位，不展示破图。
2. 没有商品关联时显示「暂未关联商品」；有商品但价格缺失时显示「价格未提供」。不因原视频没有关联商品而隐藏已有作者和视频数据。
3. 「查看商品」使用当前关联商品的有效链接，在新标签页打开；链接缺失时不提供可点击按钮。
4. 不展示「值得参考的表达」及其标签、人工精选小字、原视频商品参考小字，以及底部重复的发布时间、来源、更新时间信息组。
5. 本次不增加作者完整资料、合作联系、投放数据或评论列表等二级功能。

### 9.5.1 入口与带入信息

3. 带入当前参考视频、标题、来源、可用时长及关联商品信息，沿用现有高保真复刻任务流程。关联商品用于理解原视频，不自动当成用户要创作的新商品。
4. 从分析结果点击「去复刻」时，同样传递当前素材及已有可复用的分析信息，不改变素材归属。
5. 返回按钮回到进入前的来源页面；从带货精选或我的收藏进入时恢复对应列表，从已有分析结果进入时返回该结果。返回不取消收藏、不删除已有任务。

### 9.5.2 工作台与步骤

以图3、图4为准：顶部展示返回、当前参考素材标题和刷新；左侧为竖版视频；右侧为流程步骤及大面积浅色进度面板。

| 阶段 | 左侧视频区 | 右侧进度区 |
| --- | --- | --- |
| 下载源视频 | 深色占位、加载环、文案「视频下载中」 | 「正在下载源视频」及下方进度动画；删除圆形下载按钮，不额外提供手动开始下载操作 |

### 9.5.4 后续创作衔接边界

1. **新商品信息确认：**用户确认本次要推广的商品，沿用现有商品选择与信息确认能力。原视频关联商品仅作参考，不能未经确认替用户选定；目标商品未满足现有必填要求时不能继续。
2. **脚本转写：**使用参考素材的拆解结果与用户确认的新商品信息，进入既有脚本转写、检查和调整流程。不能仍使用原视频的商品信息生成用户的新脚本。
3. **视频生成：**用户完成既有脚本确认后，再按现有流程提交视频生成。点击素材详情的「复刻」只发起前置准备，不代表已经生成视频。
4. 本次新增重点为素材详情到复刻工作台的传递，以及下载、拆解两个中间状态；商品字段、脚本编辑、生成参数及生成结果页沿用已有需求，不另起一套规则。
5. 新素材进入复刻时不得静默覆盖用户已有商品选择、脚本或视频结果；正在进行的同一任务应进入已有任务，创建其他任务沿用现有新建约定。

### 9.5.5 失败与恢复

- 下载失败：提示「视频下载失败，请重试」，保留当前参考素材，允许重试或返回，不提前进入爆款拆解。
- 拆解失败：提示「视频拆解失败，请重试」，保留已下载视频和当前任务信息；重试从失败步骤开始，不重复下载仍有效的视频。
- 源视频已失效、访问权限变化或素材不可处理：展示明确原因，后续步骤不可继续，不生成空白脚本或假成功状态。
- 页面刷新、网络短时异常与任务本身失败区分处理；获取状态失败时允许刷新查询，不直接重新发起任务。
- 取消收藏不取消已有复刻任务；返回、刷新或重复点击不应额外创建重复任务。计费、额度及超时按现有高保真复刻规则执行。
