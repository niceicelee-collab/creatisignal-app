# 灵感发现｜筛选优化需求 V3（简版）

更新日期：2026-09-03。用途：供产品、设计和研发确认功能。本次仅输出需求与图片原型，未修改线上页面或业务代码。

## 1. 目标与范围

用户通过搜索、品类、平台、市场、投放状态、投放日期、时长和表现数据，快速找到适合参考复刻的素材；支持保存常用条件组合，下次一键复用。

本期全部为 P0：品类原位展开、三个数据区间筛选、保存与复用筛选，以及下述必要交互。时长只是复刻参考，不建立 AI 难度评分。无需新增报表、共享筛选、自动推荐或自定义区间。

## 2. 页面布局与基础筛选

页面从上到下：品类 → 搜索及基础条件 → 素材时长 → 数据筛选与保存按钮 → 已选条件及结果列表。

| 功能 | 规则 | 默认值 |
|---|---|---|
| 品类 | 沿用现有品类词库和分类关系，不照搬参考产品的达人分类。默认一行，点击右侧“展开”原位显示其他品类并把下方内容向下推；“收起”恢复一行。品类单选，收起不清空选择，已选条件栏始终展示所选品类。 | 全部、收起 |
| 关键词 | 沿用现有搜索逻辑，可以与品类组合，不强制先搜索。 | 空 |
| 平台 | 单选，沿用现有支持的平台。 | 当前平台；首次进入为 TikTok |
| 国家/地区 | 按投放国家/地区筛选，支持多选。 | 全部 |
| 投放状态 | 投放中、已停止、全部；状态未知不视为投放中。 | 投放中 |
| 投放日期 | 单选：最近7天、最近14天、最近30天、最近90天、全部。 | 最近14天 |
| 素材时长 | 多选：全部、≤15秒、15–30秒、30–45秒、45–60秒、>60秒。具体档位左开右闭，第一档为大于0且≤15秒；例如15秒属于第一档，30秒属于第二档。 | ≤15秒 |
| 排序 | 单选：播放量、点赞数、评论数、CTR、消耗、最新。数值降序，最新按首次投放日期降序；仅展示平台支持的指标，估算消耗标为“预估消耗”。 | 播放量降序；不支持时为最新 |

投放日期暂按“平台提供的首次投放日期”定义，按站点统一时区计算并包含今天；最近14天指今天及之前13个自然日。不能用抓取时间或上传时间替代。缺少首次投放日期的素材只在日期选择“全部”时出现。

## 3. 新增三个数据筛选

参照参考图的“字段名：当前区间”胶囊下拉形式，常驻显示：点赞数：全部、消耗（币种）：全部、触达受众：全部。三项分别单选，均默认“全部”。筛选限制数值范围，排序只决定结果顺序，两者独立。

以下是建议初始档位，并非已经验证的数据分布：

| 指标 | 下拉选项 |
|---|---|
| 点赞数 | 全部；<1,000；1,000–<1万；1万–<5万；5万–<10万；≥10万 |
| 消耗（原型暂按 USD） | 全部；<$100；$100–<$500；$500–<$1,000；$1,000–<$5,000；≥$5,000 |
| 触达受众（人） | 全部；<1万；1万–<10万；10万–<50万；50万–<100万；≥100万 |

- 区间下限包含、上限不包含；第一档包含有效数值0，未知不等于0。
- 正式消耗币种需与现有数据确认一致。不同币种不能直接混合筛选；若使用转换后的数值，必须与展示和排序使用同一转换口径。实际值与预估值不可混淆。
- 触达受众使用数据源提供的去重人数，不以播放量或曝光量代替，不跨广告简单相加。
- 数据筛选、列表展示、排序使用同一数据字段和统计窗口。投放日期仅筛选素材，不把指标自动改为最近14天的表现。
- 选择具体区间时排除该指标缺失的素材；“全部”包含缺失数据。缺失值显示“—”，排序时排在末尾。平台不支持的筛选应禁用并说明原因。

## 4. 保存与一键复用常用筛选

在数据筛选行右侧增加“常用筛选”和“保存当前筛选”两个按钮。

### 保存流程

1. 用户组合任意筛选条件，点击“保存当前筛选”。
2. 弹出轻量命名框，名称必填，例如“美国猫窝·近14天”。
3. 保存成功后加入“常用筛选”列表；同名覆盖需确认，不静默覆盖。

保存内容：关键词、品类、平台、国家/地区、投放状态、投放日期选项、时长多选、点赞区间、消耗区间及币种、触达受众区间、排序指标及方向。不保存结果数据、分页位置、下拉菜单开关或品类展开状态。

### 复用与管理

- 按登录账号保存，不仅存在当前浏览器临时状态。下次进入可从“常用筛选”点击名称，一次性应用全部条件、回到第一页并查询最新结果。
- 日期保存为“最近14天”等相对选项，每次复用时重新计算日期，不能保存成当时的固定起止日期。
- 用户应用组合后手动调整条件，不自动覆盖已保存组合；需要主动再次保存。
- 每个组合提供重命名、删除；删除需确认，不影响当前查询结果或素材资产。
- 首次没有组合时显示“暂无常用筛选”；保存失败保留名称与条件，支持重试。
- 如果保存的品类、平台或指标已不可用，提示具体失效条件并要求用户调整，不静默忽略后查询。
- 保存组合不改变页面默认规则；本期不增加“设为默认”或团队共享功能。

## 5. 通用交互与保留要求

- 同一维度多选是“或”，不同维度之间是“且”。时长选中≤15秒与15–30秒，表示所有不超过30秒的素材。
- 时长“全部”与具体档位互斥；取消全部具体档位后恢复“全部”。
- 改变筛选后刷新结果，保留其他条件并回到第一页。一次只展开一个下拉菜单；品类原位展开不属于浮层。
- 已选条件栏展示生效的条件及非“全部”的数据区间，支持查看当前组合；无结果不自动放宽条件。加载中展示加载状态，失败提供重试入口。
- “清除筛选”：关键词清空，品类、国家、状态、日期、时长、三个数据项恢复全部，保留当前平台与排序。
- “恢复默认”：关键词空、品类全部、国家全部、投放中、最近14天、≤15秒、三个数据项全部、默认排序，保留当前平台。两个操作都不删除保存的组合。
- 保留素材卡片上的时长、状态和表现数据。按钮与下拉支持键盘操作，选中状态同时使用文字/勾选提示，不仅依靠颜色。
- 不恢复已删除的页面副标题、时长说明句、“示例数据”文案及≤15秒下方的小标签。按钮直接显示符号与时长。

## 6. 最小验收清单

1. 初次进入：投放中＋最近14天＋≤15秒，三个数据项均为全部。
2. 品类展开后其他控件向下移动，不被遮挡；选中第二行品类后收起，筛选和已选条件不丢失。
3. 1,000个点赞归入“1,000–<1万”，不归入“<1,000”；缺失数据不当作0。
4. 选择“美国＋投放中＋最近14天＋≤30秒＋点赞1万–<5万＋消耗$100–<$500＋触达10万–<50万”，结果必须同时满足所有条件，且按所选指标排序。
5. 保存上述组合、离开后重新进入，点击组合可一次恢复所有条件；后天复用时“最近14天”相应向后滚动。
6. 手动修改已应用组合不会覆盖原组合；删除组合不会删除素材。保存失败或组合失效时有明确提示。
