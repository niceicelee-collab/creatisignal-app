创意助手视频参考生成需求方案

版本 V1.0 · 2026 年 9 月 17 日 · 配套 16 张原型状态图

1 需求范围与结论

在现有「创意生成」输入框内增加「参考视频」入口。用户可以上传视频，结合商品图、数字人和提示词，参考动作、运镜、节奏或风格生成新视频。保留现有模型、Hook 模板、分辨率、时长、比例、音频设置。

上传参考视频后，商品图、数字人和输出参数不应整体禁用。 四个目标模型都支持图像与视频组合参考；真正需要限制的是输入规格、分类数量、累计时长、特定任务类型和模型支持的输出选项。[S1–S4]

本期提供参考生成，不新增视频编辑、延长、首尾帧、独立音频上传或在线剪辑入口。文档仍覆盖已有首尾帧流程与参考生成的冲突，以及提示词被模型识别成编辑任务时的处理。首尾帧相关原型为条件场景：只有现有流程确实使用首尾帧时才需要落地。

接口基准： Seedance 按火山方舟官方 API，Wan 3.0 按阿里云百炼官方 API。实际项目服务商、账号和地域尚未指定，接入时需确认字段透传及账号能力。本文数值是已查阅的官方文档约束，不代表已对项目账号完成调用测试。

3 页面流程与基础状态

1. 选模型：立即更新上传说明、图片／视频额度、时长和分辨率可选范围。

2. 添加视频：支持点击选择和拖入多个文件；进入「上传中 → 校验中 → 可用／失败」。每个文件独立显示进度、原因和重试／移除操作。

3. 校验通过：显示封面、文件名、真实时长、@视频N、预览／替换／删除。预览播放与模型输入是两件事；浏览器不支持解码时提示无法本地预览，不据此断定 API 不支持。

4. 组合参考：商品图用于外观、数字人用于人物、视频用于动作或运镜，提示词说明各素材用途。参考用途用文字描述，不新增虚构的“动作强度”等 API 开关。

5. 提交生成：所有参与提交的素材可用、没有硬冲突、提示词有效时允许生成；上传或校验尚未完成时按钮显示「等待素材就绪」。

6. 结果处理：获得任务 ID 后进入排队／生成状态；只有生成结果成功才显示完成。异步失败保留原素材和参数，允许返回调整。

产品规则：上传时被拒绝的新增文件不进入有效素材集合，也不占额度；用户主动提交选择前应看到成功／失败清单。原有素材有效时可继续生成，提示“仅使用已通过校验的素材”。模型切换后仍留在表单内的不兼容素材则会阻止提交，必须处理，不能悄悄丢弃。

上传、替换、删减视频和修改模型／分辨率／时长后重新获取积分预估。上传次数不直接当成生成费用；原型未写死截图中的 150 积分。

4.1 Hook 和音频具体说明

Hook 是产品模板内容，不是模型 API 的独立互斥参数。用户可以要求“前 3 秒采用 Hook 模板，后续动作参考视频1”，两者可以共存。提示词字面出现“替换”也不应一律拦截，需保留实际语义和平台反馈。

“带音频／无声音”控制输出音轨。上传带原声视频不强制开启输出音频；选择无声音也不自动删除参考视频。原声是否参与具体生成由模型理解与提示词决定，本期不新增“保留原声”独立开关。数字人若依赖声音素材，按实际接口的音频输入限制校验，不能仅因 UI 叫“数字人”就豁免。

4.2 Seedance 2.5 特殊任务边界

普通参考生成 reference 可在模型范围内自由选比例和时长。视频编辑 edit 要求存在 4–30 秒视频、ratio=adaptive、duration=-1；延长 extend 要求参考视频、ratio=adaptive。首帧／首尾帧生成也只允许 ratio=adaptive。这些是任务类型限制，不是“上传任何视频后都锁定参数”。本期仅实现 reference；编辑／延长不提供入口。[S1][S2]

显式指定 reference 仍不能保证模型绝不会误判；官方说明任务意图不一致时可能返回 InvalidParameter.TaskTypeMismatch，参数不兼容可能返回 InvalidParameter.TaskTypeConstraint。P16 必须展示这类异步失败，不能只验证前端表单合法。[S1][S2]

Seedance 真人相关限制：普通直传的真人人脸图／视频受限；官方提供信任模型原始产物、预置虚拟人像、已授权真人素材等使用路径。现有数字人是否满足相应机制需接入核对，不能用一个“我已授权”复选框替代平台要求。[S1][S2]

6 关键验收与待确认项

6.1 验收要点

• 四个模型按各自限制校验。Seedance 2.5 的 2 秒参考视频有效；2.0/Mini 的 1.9 秒无效；Wan 的 1 秒有效。累计值不因显示四舍五入而误通过。

• 单视频 200 MB 为 Seedance 文档允许边界，Wan 边界为 100 MB；超过边界阻止加入。MB 对应字节阈值按实际服务商确认后固定，不能前后端口径不一致。

• 2.0/Mini 的第 4 段、2.5 的第 11 段、Wan 的第 6 段不可加入；数量达上限本身不阻止现有合法任务生成。

• 视频 8 秒＋6 秒后新增 3 秒应拒绝；保留原来的 14 秒素材组合。图像额度不得兑换视频额度。

• Wan 输入 12 秒＋输出 18 秒可通过，输出 19 秒不可通过；输入 12.4 秒时输出上限 17 秒。

• Mini 不能选 1080P；2.0 和 2.5 在普通参考生成中不因上传视频而禁用 1080P、指定比例或有声输出。

• 商品图、可用数字人人像和视频可一起提交。数字人的底层素材计数正确；存在首尾帧角色时才触发角色冲突。

• 切换模型不丢素材、不静默更改时长；取消切换完整保留原配置。切换并调整后，所有硬冲突消失才可生成。

• 删除视频后额度恢复；原引用不会错指；用户当前合法时长不会自行改变；上传失败文件不会误进入生成请求。

• 平台拒绝素材或任务类型不匹配时展示明确失败原因，保留表单；任务 ID 返回不等于生成完成。

6.2 接入前只需确认这些事项

1. 实际服务商、账号地域与四个模型的具体调用标识，及第三方接口是否比官方更严格。

2. Seedance 输入高分辨率文档差异、Wan 编码支持、MB 的字节口径，按真实接口联调确认。

3. 现有数字人传入的是图片、视频、音频还是组合；真人／虚拟人素材的可用资格如何确定。

4. 现有商品图是否被当作首帧传入、0/8 代表什么；据此确定 P11 是否需要，以及计数器改动位置。

5. 上传后可被模型读取的 URL／素材 ID 及其有效期、文件校验结果、积分预估返回方式。临时 URL 失效时保留素材卡并要求重新获取可用来源，不能直接重试旧链接。
