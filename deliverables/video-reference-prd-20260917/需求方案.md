# 创意助手视频参考生成需求方案

版本 V1.0 · 2026 年 9 月 17 日

## 1 需求范围与结论

在现有「创意生成」输入框内增加「参考视频」入口。用户可以上传视频，结合商品图、数字人和提示词，参考动作、运镜、节奏或风格生成新视频。保留现有模型、Hook 模板、分辨率、时长、比例、音频设置。

**上传参考视频后，商品图、数字人和输出参数不应整体禁用。** 四个目标模型都支持图像与视频组合参考；真正需要限制的是输入规格、分类数量、累计时长、特定任务类型和模型支持的输出选项。[S1–S4]

本期提供参考生成，不新增视频编辑、延长、首尾帧、独立音频上传或在线剪辑入口。文档仍覆盖已有首尾帧流程与参考生成的冲突，以及提示词被模型识别成编辑任务时的处理。首尾帧冲突属于条件场景：只有现有流程确实使用首尾帧时才需要落地。

**接口基准：** Seedance 按火山方舟官方 API，Wan 3.0 按阿里云百炼官方 API。实际项目服务商、账号和地域尚未指定，接入时需确认字段透传及账号能力。本文数值是已查阅的官方文档约束，不代表已对项目账号完成调用测试。

## 2 API 参数要求

### 2.1 参考视频输入要求

下表为 API 限制。达到数量上限可以生成，但不能继续添加该类型素材。

| 项目 | Seedance 2.5 | Seedance 2.0 | Seedance 2.0 Mini | Wan 3.0 |
|---|---|---|---|---|
| 最多视频数 | 10 段 | 3 段 | 3 段 | 5 段 |
| 单个视频时长 | 2–30 秒 | 2–15 秒 | 2–15 秒 | 1–15 秒 |
| 所有视频累计时长 | ≤30 秒 | ≤15 秒 | ≤15 秒 | ≤15 秒 |
| 单文件大小 | ≤200 MB | ≤200 MB | ≤200 MB | ≤100 MB |
| 文件格式 | MP4、MOV | MP4、MOV | MP4、MOV | MP4、MOV |
| 视频帧率 | 24–60 fps | 24–60 fps | 24–60 fps | ≥16 fps |
| 宽、高各自范围 | 300–6000 px | 300–6000 px | 300–6000 px | 240–4096 px |
| 宽高比 | 宽÷高在 0.4–2.5 | 同左 | 同左 | 长边÷短边≤8 |
| 总像素数 | 407,696–8,295,044 | 同左 | 同左 | 未单列总像素限制 |
| 视频传入方式 | 公网 URL 或 `asset://<ASSET_ID>` | 同左 | 同左 | HTTP(S) URL 或官方上传接口返回的临时 OSS URL |

来源：[S1][S3]。Seedance 2.5 上述 2–30 秒用于参考生成；视频编辑任务另要求 4–30 秒，不应套用于普通参考生成。

**编码补充：** Seedance 的 MP4/MOV 视频编码支持 H.264/AVC、H.265/HEVC；MP4 音频编码为 AAC、MP3，MOV 额外支持 PCM。Wan 本次查阅的 API 页未明确限定视频编码，不将 Seedance 编码表套用给 Wan；需要按实际接口测试确认。[S1][S3]

**输入清晰度的文档差异：** Seedance API 页列出 480p/720p/1080p/4k，而 2.5 教程的输入视频段仍只列 480p/720p，尺寸上限却相同。高分辨率输入的实际支持状态需联调确认。页面完整校验需检查实际尺寸、像素积及比例，不能仅凭“720p”标签判断合格。[S1][S2]

### 2.2 与其他参考素材共用的数量规则

| 项目 | Seedance 2.5 | Seedance 2.0 / Mini | Wan 3.0 |
|---|---|---|---|
| 参考图片上限 | 30 张 | 9 张 | 10 张 |
| 参考视频上限 | 10 段 | 3 段 | 5 段 |
| 图、视频、音频官方总上限 | 50 个（30+10+10） | 15 个（9+3+3） | 20 个（10+5+5） |
| 本期仅图片＋视频时理论上限 | 40 个 | 12 个 | 15 个 |
| 图像与视频能否混用 | 可以 | 可以 | 可以 |
| 单张参考图大小 | <30 MB | <30 MB | ≤20 MB |

来源：[S1][S2][S3][S4]。分类额度不可互换：少传图片不能增加视频数量；累计视频时长仍独立受限。Seedance 图片宽高各为 300–6000 px、宽÷高为 0.4–2.5；Wan 图片宽高各为 240–8000 px、长短边比不超过 8。[S1][S3]

**数字人的计数按实际素材计算。** 商品图和数字人人像图共同占用图片额度；若数字人实际附带视频或音频，则分别占用相应额度，并参与对应时长校验。一张数字人卡片不等于一个 API 素材。上线前应核对现有数字人素材形态；如携带音频，Seedance 2.5 音频最多 10 段、单段 2–30 秒且累计≤30 秒，2.0/Mini 最多 3 段、单段 2–15 秒且累计≤15 秒；Wan 最多 5 段、单段 1–15 秒且累计≤15 秒，三者单音频均≤15 MB。[S1][S3]

截图中的 `0/8` 需确认原有含义：若为素材数量，改为分类计数；若为任务并发数量，则保留并另增素材计数。不要把 8 直接当成参考视频上限。

### 2.3 输出参数及联动

| 输出项目 | Seedance 2.5 | Seedance 2.0 | Seedance 2.0 Mini | Wan 3.0 |
|---|---|---|---|---|
| API 分辨率 | 480p / 720p / 1080p | 480p / 720p / 1080p / 4k | 480p / 720p | 480P / 720P / 1080P |
| API 生成时长 | 4–30 秒整数；或 -1 | 4–15 秒整数；或 -1 | 4–15 秒整数；或 -1 | 2–30 秒整数；或 -1 |
| 指定比例 | 16:9、9:16、1:1、4:3、3:4、21:9 | 同左 | 同左 | 16:9、9:16、1:1、4:3、3:4 |
| 自适应比例 | `adaptive` | `adaptive` | `adaptive` | `adaptive` |
| 有声／无声 | `generate_audio=true/false` | 同左 | 同左 | `parameters.audio=true/false` |
| 普通视频参考后能否指定时长、比例 | 可以 | 可以 | 可以 | 可以，但受输入输出总时长限制 |

来源：[S1][S3]。`-1` 表示模型智能选择；本期仍使用用户明确指定的整数时长，便于控制生成结果与积分预估。页面沿用 720P/1080P 和现有五种比例，不因 API 有更多选项就扩展页面；Mini 将 1080P 置灰，720P 正常可选。480P、4K、21:9 列在 API 表中，未纳入本期新增页面选项。

**Wan 时长联动：** 令 T 为所有有效输入视频的真实时长之和，允许的最大整数输出时长为 `min(30, floor(30-T))`。例如 T=12 秒时，输出最长 18 秒；T=12.4 秒时，输出最长 17 秒。不得先对每段视频取整再求和。用户已选 20 秒时不静默改成 18 秒，先提示并提供「改为 18 秒」操作。[S3]

Seedance 普通参考生成未在上述文档中设置 Wan 的输入＋输出≤30 秒规则，不跨模型套用。上传视频也不自动锁定为视频原比例、不自动关闭生成音频。[S1]

### 2.4 与页面直接相关的 API 字段

| 页面内容 | Seedance | Wan 3.0 | 必填与要求 |
|---|---|---|---|
| 所选模型 | `model` | `model` | 必填，对应实际服务版本 |
| 提示词 | `content[]` 中 `type=text`、`text` | `input.prompt` | API 允许部分素材模式不填文本；产品本期要求有明确生成描述 |
| 参考视频 | `type=video_url`、`video_url.url`、`role=reference_video` | `input.media[]` 中 `type=reference_video`、`url` | 每段独立传入，来源有效且可被模型读取 |
| 商品图／人像图 | `type=image_url`、`image_url.url`、`role=reference_image` | `type=reference_image`、`url` | 视频参考模式下不能误用首帧字段 |
| 生成分辨率 | `resolution`，如 `720p` | `parameters.resolution`，如 `720P` | 注意大小写不同 |
| 生成时长／比例 | `duration` / `ratio` | `parameters.duration` / `parameters.ratio` | 显式提交页面所选值 |
| 输出声音 | `generate_audio` | `parameters.audio` | 与输入视频是否有原声分开处理 |
| 参考任务类型 | 仅 2.5：`omni_reference_task_type=reference` | 本次 API 无同名字段，按素材与提示词判定 | 不向 2.0/Mini 或 Wan 盲传 2.5 专用字段 |

来源：[S1][S3]。页面的 `@商品图1`、`@数字人1`、`@视频1` 是素材引用标签，不是额外的 API 参数。提交时应映射为模型可识别的对应图／视频编号，不能把 `@视频1` 当作视频 URL。删除、替换、重排后，引用仍要指向正确素材。

Seedance 中文 500 字、英文 1000 词是提示词长度建议，不作为 API 硬上限。Wan 最大 20,000 字符，文档说明超出会截断；产品应提前提示并阻止超长提交，避免描述被无声截断。[S1][S3]

## 3 页面流程与基础状态

1. 选模型：立即更新上传说明、图片／视频额度、时长和分辨率可选范围。
2. 添加视频：支持点击选择和拖入多个文件；进入「上传中 → 校验中 → 可用／失败」。每个文件独立显示进度、原因和重试／移除操作。
3. 校验通过：显示封面、文件名、真实时长、`@视频N`、预览／替换／删除。预览播放与模型输入是两件事；浏览器不支持解码时提示无法本地预览，不据此断定 API 不支持。
4. 组合参考：商品图用于外观、数字人用于人物、视频用于动作或运镜，提示词说明各素材用途。参考用途用文字描述，不新增虚构的“动作强度”等 API 开关。
5. 提交生成：所有参与提交的素材可用、没有硬冲突、提示词有效时允许生成；上传或校验尚未完成时按钮显示「等待素材就绪」。
6. 结果处理：获得任务 ID 后进入排队／生成状态；只有生成结果成功才显示完成。异步失败保留原素材和参数，允许返回调整。

产品规则：上传时被拒绝的新增文件不进入有效素材集合，也不占额度；用户主动提交选择前应看到成功／失败清单。原有素材有效时可继续生成，提示“仅使用已通过校验的素材”。模型切换后仍留在表单内的不兼容素材则会阻止提交，必须处理，不能悄悄丢弃。

上传、替换、删减视频和修改模型／分辨率／时长后重新获取积分预估。上传次数不直接当成生成费用；积分预估使用实际计费规则，不固定为截图中的 150 积分。

## 4 冲突规则与展示

以下“API”指官方接口约束，“产品”指本方案提出的页面处理方式。每条分别规定触发条件与处理方式。

| 编号 | 触发条件与性质 | 页面展示和解决方式 |
|---|---|---|
| C01 | 文件格式、大小、单段时长、帧率或尺寸不合法；API | 文件行标红并列明实际值和允许值；拒绝加入，可替换／移除。编码解析失败不猜测为合格 |
| C02 | 视频数量达到上限；API | 视频入口置灰，旁边明确“已达 3 段上限”；图片额度剩余时商品图／数字人入口仍可用。删除一段后恢复 |
| C03 | 新视频导致累计时长超限；API | 展示“已用 14 秒，新增 3 秒，合计 17 秒，上限 15 秒”；新增文件不加入。允许删除／替换旧视频后重选 |
| C04 | 商品图＋数字人人像达到图片上限；API＋素材映射 | 两个会增加图片的入口同时受限；视频仍按自己的数量和时长判断。替换已有数字人且不增加数量仍允许 |
| C05 | Mini 的 1080P 不受支持；API | 分辨率面板保留 1080P 但置灰，常驻“此模型最高支持 720P”；不将其描述为“上传视频导致” |
| C06 | Wan 输入视频合计＋所选生成时长>30 秒；API | 时长字段标红，面板标明当前最长 N 秒并禁用超出区间，提供「改为 N 秒」；修改前不可提交 |
| C07 | 切换模型后素材／输出参数不兼容；API＋产品 | 确认面板列出每项差异；「保留原模型」或「切换并手动调整」。后者保留素材和原值但标红，解决前禁用生成；禁止自动删文件或改参数 |
| C08 | 已有首帧／尾帧与参考素材混用；API，条件场景 | 不禁用全部图片。提示“首尾帧约束与视频参考不能同时使用”；用户可保留原模式，或确认取消首尾帧约束并将图片改为普通参考，随后按新规则重验 |
| C09 | Hook 与视频参考描述有潜在内容矛盾；产品 | 显示非阻断提醒和「修改描述／取消模板」，不把 Hook 自动禁用。无法判断是否冲突时只提供说明，不宣称已检测出语义错误 |
| C10 | 删除素材后仍被提示词引用；产品 | 删除前说明影响；删除后高亮失效引用，提供移除引用或重新选择素材。解决失效引用前不可提交，不把旧编号悄悄指向另一段视频 |
| C11 | 删除／替换后限制解除；产品 | 即时恢复对应入口；Wan 重新计算输出上限。保留当前合法参数，不自动恢复此前较长的生成时长；重新预估积分 |
| C12 | Seedance 真人素材未满足平台输入条件；API | 素材或任务标为不可用，解释需符合平台授权／信任素材机制；提供替换素材、选择可用数字人。仅以明确的素材状态或平台返回为依据，不凭外观猜测真人 |
| C13 | Seedance 2.5 参考任务被判定为编辑／延长；API＋产品 | 展示失败原因和「修改描述」入口，保留表单；推荐改为“参考视频1的运镜，生成一段新视频”。不自动把比例／时长锁定或改为编辑模式 |


### 4.1 Hook 和音频具体说明

Hook 是产品模板内容，不是模型 API 的独立互斥参数。用户可以要求“前 3 秒采用 Hook 模板，后续动作参考视频1”，两者可以共存。提示词字面出现“替换”也不应一律拦截，需保留实际语义和平台反馈。

“带音频／无声音”控制输出音轨。上传带原声视频不强制开启输出音频；选择无声音也不自动删除参考视频。原声是否参与具体生成由模型理解与提示词决定，本期不新增“保留原声”独立开关。数字人若依赖声音素材，按实际接口的音频输入限制校验，不能仅因 UI 叫“数字人”就豁免。

### 4.2 Seedance 2.5 特殊任务边界

普通参考生成 `reference` 可在模型范围内自由选比例和时长。视频编辑 `edit` 要求存在 4–30 秒视频、`ratio=adaptive`、`duration=-1`；延长 `extend` 要求参考视频、`ratio=adaptive`。首帧／首尾帧生成也只允许 `ratio=adaptive`。这些是任务类型限制，不是“上传任何视频后都锁定参数”。本期仅实现 reference；编辑／延长不提供入口。[S1][S2]

显式指定 reference 仍不能保证模型绝不会误判；官方说明任务意图不一致时可能返回 `InvalidParameter.TaskTypeMismatch`，参数不兼容可能返回 `InvalidParameter.TaskTypeConstraint`。页面必须展示这类异步失败，不能只验证前端表单合法。[S1][S2]

Seedance 真人相关限制：普通直传的真人人脸图／视频受限；官方提供信任模型原始产物、预置虚拟人像、已授权真人素材等使用路径。现有数字人是否满足相应机制需接入核对，不能用一个“我已授权”复选框替代平台要求。[S1][S2]

## 5 关键验收与待确认项

### 5.1 验收要点

- 四个模型按各自限制校验。Seedance 2.5 的 2 秒参考视频有效；2.0/Mini 的 1.9 秒无效；Wan 的 1 秒有效。累计值不因显示四舍五入而误通过。
- 单视频 200 MB 为 Seedance 文档允许边界，Wan 边界为 100 MB；超过边界阻止加入。MB 对应字节阈值按实际服务商确认后固定，不能前后端口径不一致。
- 2.0/Mini 的第 4 段、2.5 的第 11 段、Wan 的第 6 段不可加入；数量达上限本身不阻止现有合法任务生成。
- Seedance 2.0／Mini、Wan 3.0 已有视频 8 秒＋6 秒后新增 3 秒应拒绝；保留原来的 14 秒素材组合。Seedance 2.5 按 30 秒累计上限单独校验。图像额度不得兑换视频额度。
- Wan 输入 12 秒＋输出 18 秒可通过，输出 19 秒不可通过；输入 12.4 秒时输出上限 17 秒。
- Mini 不能选 1080P；2.0 和 2.5 在普通参考生成中不因上传视频而禁用 1080P、指定比例或有声输出。
- 商品图、可用数字人人像和视频可一起提交。数字人的底层素材计数正确；存在首尾帧角色时才触发角色冲突。
- 切换模型不丢素材、不静默更改时长；取消切换完整保留原配置。切换并调整后，所有硬冲突消失才可生成。
- 删除视频后额度恢复；原引用不会错指；用户当前合法时长不会自行改变；上传失败文件不会误进入生成请求。
- 平台拒绝素材或任务类型不匹配时展示明确失败原因，保留表单；任务 ID 返回不等于生成完成。

### 5.2 接入前只需确认这些事项

1. 实际服务商、账号地域与四个模型的具体调用标识，及第三方接口是否比官方更严格。
2. Seedance 输入高分辨率文档差异、Wan 编码支持、MB 的字节口径，按真实接口联调确认。
3. 现有数字人传入的是图片、视频、音频还是组合；真人／虚拟人素材的可用资格如何确定。
4. 现有商品图是否被当作首帧传入、`0/8` 代表什么；据此确定是否需要首尾帧冲突处理，以及计数器改动位置。
5. 上传后可被模型读取的 URL／素材 ID 及其有效期、文件校验结果、积分预估返回方式。临时 URL 失效时保留素材卡并要求重新获取可用来源，不能直接重试旧链接。
