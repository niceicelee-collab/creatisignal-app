# 带货精选版本合并说明

合并日期：2026-09-21。当前版本已接入项目的 Next.js 页面、导航、素材详情和现有高保真复刻工作台。

## 入口

| 功能 | 项目入口 | 路径 |
| --- | --- | --- |
| 带货精选 | 发现 → 带货精选 | `/discover/curated` |
| 我的收藏 | 资产库 → 我的收藏 | `/assets/favorites` |
| 素材详情 | 点击带货精选或收藏中的素材 | 共用弹窗 |
| 素材分析 | 素材详情 → 分析；任务 → 我的任务 | `/reports/material/[id]` |
| 创意衔接 | 素材详情 → 复刻；创作 → 高保真复刻 | `/replicate/material/[id]` |

## 已合并行为

- 热门地区后提供国家搜索，支持中文、英文和国家代码搜索，结果只显示中文；249 个国家与地区按英文名 A–Z 排序，选中后才应用筛选。
- 达人和商品分类沿用本版分类表，超过一行显示展开／收起。播放量、点赞、粉丝、时长、AI 视频、日期等条件可组合筛选，使用自定义浮层下拉框。
- 默认每页 10 条，可切换 20／50 条；不足一页按实际数量展示。保留排序、筛选、分页及返回位置。
- 列表和详情共用素材数据，详情包含互动指标、预估 GMV、预估销量、作者及关联商品。缺失数据与数值 0 分开处理。
- 收藏状态在带货精选和我的收藏之间同步，收藏按时间倒序；失效素材保留信息并禁用分析、复刻入口。
- 分析使用任务菜单承载的居中双栏页面；复刻使用创作菜单承载的四步工作台。两者都有下载和分析两个独立中间状态。
- 模拟下载 3 秒，再进入模拟分析 12 秒，随后显示演示结果。刷新浏览器恢复任务；页面内“刷新”按钮重新演示流程。
- 已完成的分析可直接进入复刻，复用参考素材和分析结果；新商品信息初始为空，填写后进入现有脚本及视频生成流程。
- 当前素材的名称、封面和商品信息传入复刻流程，避免串用已有示例项目的信息。商品文本、脚本和生成参数可在刷新后恢复。

## 当前数据和服务边界

- 当前为本版演示数据：10 条可用素材及 1 条失效收藏示例，尚未接入真实 TikTok 数据、下载和分析服务。
- 婚礼礼服素材 `m2` 使用项目已有的匹配视频。其他素材使用本版封面并显示“视频源尚未接入”，不会播放不相关视频。
- 示例未提供真实原视频及商品链接，对应外链按钮暂不可用。接入有效链接后再开放。
- 分析结果及脚本为演示内容，页面已作标识；既有视频生成环节仍为模拟流程。本次未接入新的模型服务，也未开放 Seedance 2.5。
- 收藏、任务和筛选使用当前浏览器本地存储，并按项目空间隔离；当前项目只有演示账号，尚不支持真实账号及跨设备同步。
- 新商品图片与数字人沿用现有工作台行为，暂未增加文件持久化或上传服务。文本草稿恢复不代表上传文件也能恢复。
