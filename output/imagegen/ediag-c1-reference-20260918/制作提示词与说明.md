# EDIAG C1 参考图制作记录

生成方式：内置 image_gen 图像编辑工具。

素材来源：用户提供的商品宣传截图。本文件夹内六张 PNG 为选定的最终输出，03 与 05 已替换第一版。

重要限制：这是基于截图的 AI 重组版，不是确定性裁切或逐像素复制。原截图的低分辨率、小字和暗部无法提供完整结构证据，接口内部、安装位置细节、徽标轮廓与 APP 字体不应视为已与实物逐项核验。原图未提供清晰插入前场景，因此安装部分采用同一已安装场景的整体及近景。APP 采用原素材中无遮挡的实时数据页面。
