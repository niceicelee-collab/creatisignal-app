# 电商生图模型效果与成本评测

公开盲测与官方 API 价格研究 | 2026 年 9 月 18 日

## 1 选型结论

**除了 GPT Image 2、GPT Image 2.5 和 Seedream 5.0 Pro，还应重点关注 MAI-Image-2.6、Nano Banana 2、Muse Image。Wan 2.7 标准版与 Pro 版纳入电商组图和成本专项对照；Reve 2.1 属于画质对照候选，Qwen-Image-3.0-Pro 属于文字与版式专项候选。** 电商选型应分别判断视觉质量、商品还原、修改稳定性和每张合格素材的总成本。

建议先做小规模验证，再决定默认模型。以下是根据公开证据提出的试用顺序，不是已经完成的真实商品实测排名。

| 业务目标 | 优先验证 | 选择理由 |
|---|---|---|
| 高质量广告主视觉 | GPT Image 2.5 Flare | 文生图盲测领先，官方定位偏高质量日常生成 |
| 保持商品不变的精细修改 | GPT Image 2.5 Sunburst | 编辑盲测领先，官方强调编辑精度 |
| 国内电商日常生产 | Seedream 5.0 Pro | 人民币计价清晰，支持区域编辑和图层拆分 |
| 国内低成本与连续组图 | Wan 2.7 / Pro | 标准版价格低，支持连续组图；需验证真实SKU一致性 |
| 全球 API 的质量与成本平衡 | MAI-Image-2.6 / Flash | 公开榜单表现较强；需接受 Foundry 公测状态 |
| 多参考素材合成与 4K | Nano Banana 2 | 官方具备多图参考与 4K 输出，价格档位明确 |
| 低成本批量探索 | Muse Image | 官方公开标价低；接入和计费边界还需账户验证 |

**最值得保留的组合：Seedream 5.0 Pro 做国内生产基线，Wan 2.7 做成本与组图对照，Flare 做主视觉质量基线，Sunburst 做高难度编辑，Nano Banana 2 做多参考与 4K 对照。** 有全球 API 条件时，再加入 MAI 和 Muse。推荐依据见 [S1] 至 [S14]、[S23] 至 [S25]。

### 本报告的证据范围

- 已完成：核验模型名称、公开盲测位置、官方能力和计费规则，计算预算与合格素材成本示例。
- 未执行：同一批真实 SKU 的跨模型付费生成；没有本次实测样图、商品一致性通过率、延迟 P95 或广告转化结果。
- 阅读方式：榜单是公开效果证据；能力介绍是厂商声明；试用顺序是分析判断；文中假设算例不代表模型实际通过率。

价格截止日为 2026-09-18。美元与人民币分别保留原币种，避免用假定汇率制造精确比较。会员价格、代理商价格、API 价格不混用。

### 如何理解 SOTA

综合质量领先、多参考编辑领先、特定语言排版领先和最低合格素材成本，是不同问题。本报告将榜单前列模型列为综合领先候选；将具有明确电商能力的模型列为专项候选，不把所有知名模型都称为综合第一梯队。

另一独立平台 Arena 的文生图快照把 Sunburst 排在 Flare 前面，二者均标为 Preliminary；其 GPT Image 2 测试档为 medium。[S3] 这说明评测集、用户偏好和参数会改变次序，不能混合两个平台的 Elo 分数，也不能把 max 档的排名套到 low 档。

Flare 与 Sunburst 的 AA 文生图 Elo 置信区间重叠，不能据名次断言 Flare 在所有任务上明显更好。Reve 的旧版编辑排名也不能当成 Reve 2.1 的成绩。

**对电商的实际含义：榜单可决定先测谁，但不能证明某个模型会正确保留你的商品。** Logo、接口、配件数、服装剪裁和包装小字必须单独验收；偏好票数也不是这些能力的通过率。

## 3 GPT 与 Seedream 的效果判断

### GPT Image 2.5 Flare

官方模型为 `gpt-image-2.5-flare`，可固定快照 `2026-09-08`，质量档包括 low、medium、high、xhigh、max 和 auto。官方定位偏快速、高质量日常生成。[S4]

**适合优先验证：** 活动主视觉、商品与生活方式场景融合、带短标题的广告图。公开文生图成绩支持把它作为质量上限对照。正式评测要同时测试 high 与 max：如果 max 的可用率没有抵消成本和等待时间增加，就不应默认 max。

**验收重点：** 白色背景是否出现无意颗粒、Logo 是否重绘、包装文字是否被“合理化”修改、场景光照是否改变商品颜色。这些是待检项，不是本报告已观察到的固定缺陷。

### GPT Image 2.5 Sunburst

官方模型为 `gpt-image-2.5-sunburst`，可固定 `2026-09-08` 快照；官方强调编辑精度。[S5] 结合编辑榜证据，更值得测试局部换色、去除道具、修改广告文案，以及多轮修改后保持主体。

**适合优先验证：** 已有较好底图，仅修改一个元素；复杂商品与人手互动；需要反复修图的付费交付。没有本次耗时数据，不能直接承诺它比 Flare 慢多少或节省多少返工。

### GPT Image 2

保留 `gpt-image-2-2026-04-21` 作为回归基线。[S6] 对已经可用的老流程，应比较 medium 的成本与新版本的实际提升；不必因为新版本出现就整体切换。以旧模型 high 的价格对比新模型 low 的价格，会造成误导。

### Seedream 5.0 Pro

当前官方教程模型 ID 为 `doubao-seedream-5-0-pro-260628`；支持单图、多参考图、坐标或标记指定的区域编辑，以及透明图层拆分。[S8] 这些能力适合主图改背景、区域素材替换和广告后期调整。

**重要接口边界：** 官方表列出 1K、1.5K、2K；暂不支持普通文生组图、图生组图、流式输出和联网搜索。图层拆分可以输出一张底图加最多 16 个图层，不等于一次生成一组不同商品场景图。[S8]

中文海报与多语种排版值得测试，但厂商案例不能证明批量零错字。对于不可变化的 SKU，应优先保留原商品像素、只生成或替换背景；确需重绘主体时逐项检查。

### 多参考数量不能直接换成一致性成绩

Google 官方文档列出 Gemini 3.1 Flash Image 最多 10 张物体图与 4 张人物图；Gemini 3 Pro Image 则列出 6 张物体、5 张人物、3 张风格图。[S13] 输入更多素材可能帮助模型理解商品，也可能增加冲突。必须固定参考图内容、顺序、清晰度和用途说明。

Qwen-Image-3.0-Pro 官方教程列出最多 3 张输入图、6 张输出图和 2048×2048 输出。[S15] 多图数量是接口能力，不是商品在每张图中完全一致的保证。

这些样例的提示词、商品和挑选方式不同，仅用于理解能力形态，不作为同题横评。报告不把各家最好看的图拼成“公平胜负图”。

## 5 Wan 2.7 标准版与 Pro 专项对比

本报告的 Wan 2.7 指 `wan2.7-image` 和 `wan2.7-image-pro` 两个生图模型。结合当日盲测，二者更适合列为电商工作流与成本候选，目前证据不支持将它们称为综合画质榜单的最前列。[S1][S2]

| 商品参考图生成与编辑 | 最高2K | 最高2K |
| 输入参考图 | 最多9张 | 最多9张 |
| 输出数量 | 普通1至4张；连续组图最多12张 | 普通1至4张；连续组图最多12张 |
| 颜色与局部控制 | 支持色板和交互式编辑 | 支持色板和交互式编辑 |

| 国际站新加坡区单张输出 | $0.03 | $0.075 |

能力来源 [S23][S25]，价格来源 [S16][S24]。连续组图会按实际成功输出张数计费，不是一次请求只收一张的钱。组图能力也不等于批量推理折扣。

### 相比 Seedream 与 GPT 的电商价值

**相比 Seedream Pro：** Wan 可以一次生成连续组图，标准版国内单张便宜；Seedream Pro 的价值在交互编辑和透明图层拆分。现有编辑榜证据偏向 Seedream，但具体商品组图结果必须实测。不能把 Wan Pro 的4K文生图能力用于承诺4K商品参考图编辑。

**相比 GPT 2.5：** Wan 值得优先验证规格清楚、构图简单的批量图与系列素材；GPT 的公开综合质量更强。对高价值商品图，要比较错误率和修图时间，不能只按人民币单价决定。

**品牌色控制：** 色板可设置3至10种HEX颜色及比例，属于整幅图的颜色主题约束，不保证商品色差或印刷色准。开启连续组图时色板不可用；思考模式仅在无图输入、非组图时生效。[S23] 因而“组图、指定色板、思考增强”不能默认同时开启。

### 国内同尺寸成本对照

对于单次2K商品改图、1张参考图，Wan标准版 ¥0.20、Pro ¥0.50，Seedream 2048² 为 ¥0.60。API 单价分别低约66.7%和16.7%。这是同尺寸费用差，不是同效果成本优势。

只计API且每次输出一张时，Wan标准版通过率超过 Seedream通过率的1/3、Pro超过其5/6，才有更低合格图API成本。例：若Seedream通过率假设为80%，对应门槛约26.7%与66.7%；真实通过率未知。首轮应把两款Wan都加进来，重点测试套装数量、组图一致性与局部编辑保留。

## 7 电商改图的真实计费示例

### Seedream 的尺寸和参考图费用

火山引擎规则：首张参考图免费，第 2 张起每张 ¥0.02；单图输出以 261 万像素为分界。图层拆分输出分别为 ¥0.15 和 ¥0.30，每个图层按自身像素档位计费。[S9]

| 工作流 | 每次费用 | 1,000 次费用 |
|---|---:|---:|
| 1 张参考图，输出 1536×1536 | ¥0.30 | ¥300 |
| 3 张参考图，输出 1536×1536 | ¥0.34 | ¥340 |
| 3 张参考图，输出 2048×2048 | ¥0.64 | ¥640 |
| 1 张参考图，拆出 6 个均≤261万像素的计费输出 | ¥0.90 | ¥900 |

1536² 为 235.93 万像素，低于分界；2048² 为 419.43 万像素，高于分界。请按实际宽×高算像素，不能只看“2K”文字标签。拆层示例假设总共返回 6 个计费输出，底图也应纳入返回数量核对，不是把“6 个图层加底图”仍算 6 张。

### GPT Image 2.5 的用量算例

假设一次请求没有缓存，消耗 500 文本输入 token、3,000 图像输入 token、4,000 图像输出 token，则费用为：

**500×5/1,000,000 + 3,000×8/1,000,000 + 4,000×30/1,000,000 = $0.1465。**

这是公式演示，不表示 1K、2K 或某个质量档固定消耗这些 token。后续修改请求需要再次计算输入和输出，不能只记首次生成费用。[S4][S5]

### 相同 2K 输出档的可比范围

Nano Banana 2 的图像输出为 $0.101；Nano Banana Pro 为 $0.134；Qwen-Image-3.0-Pro 国际新加坡区为 $0.075，若输入 3 张参考图则另加 $0.009，总计 $0.084。[S12][S16]

Google 还可能产生文本、思考和搜索费用。GPT 与 MAI 要补充实际用量后才能加入严格同尺寸总价对比。Seedream 2048² 单图为 ¥0.60，应使用采购实际结算汇率再换算。

**每月生成 10,000 张** 时，上述单次费用直接乘 10,000。例如 Seedream 的三参考图 2048² 工作流为 ¥6,400；这仍是生成费用，不是交付 10,000 张合格素材的总费用。

Wan中国站北京区生成10,000张分别为¥2,000和¥5,000；一次连续组图若成功返回6张，分别为¥1.20和¥3.00。即使只选用其中一张，也要将六张成本计入交付。[S24]

## 8 每张合格素材成本

建议记录两种通过率：首次输出通过率，以及允许固定轮数修改后的最终任务通过率。两者分母不同，不能混算。一个任务输出四张、挑出一张合格图时，四张的费用都属于这张交付素材。

**每张合格素材总成本 = 全部生成与编辑 API 费用 + 人工检查与修图费用 + 后处理费用，以上总和再除以合格交付张数。**

### 为什么单图便宜不等于交付便宜

以下是完全假设的算例，不对应任何实际模型：

| 同样生成 1,000 张 | 方案 A | 方案 B |
|---|---:|---:|
| 单张 API 成本 | ¥0.30 | ¥0.80 |
| 合格率 | 40% | 80% |
| API 总费 | ¥300 | ¥800 |
| 每张候选图检查时间 | 1 分钟 | 0.25 分钟 |
| 人工费，按 ¥60/小时 | ¥1,000 | ¥250 |
| 合格张数 | 400 | 800 |
| 每张合格素材成本 | ¥3.25 | ¥1.31 |

只计 API 时 A 为 ¥0.75/合格张，B 为 ¥1.00/合格张；加入检查时间后，B 更低。对于投放素材，人工找错字、修标签和反复生成，可能比 API 差价更重要。

### 便宜模型能否先生成再升级

可以尝试两段流程：低价模型探索构图，命中方向后交给精细编辑模型。要把“低价阶段被丢弃的图”和“换模型导致商品漂移的修复”同时计入账单。如果低价阶段不能可靠传递商品与构图，就未必节省总成本。

建议分别报告：每张生成成本、每个完成任务成本、每张合格交付成本、首次通过率、平均修改次数、人工分钟数、等待时间中位数和 P95。公开榜单没有这些业务指标，本报告也不填入推测值。

### 对预算的判断

先设定“关键 SKU 零明显结构错误”的门槛，再比较成本。不能让画面更美抵消型号、配件数或标签容量错误。广告 CTR、CVR、ROAS 是另一次投放实验的结果，不应由生图盲测成绩推导。

## 9 建议的电商实测方案

### 第一轮筛选

选择 12 个 SKU，覆盖美妆包装、透明玻璃、反光金属、小家电、服装和多件套；每类 2 个。每个 SKU 做 6 个任务，每题重复 2 次，共144条任务。三轮编辑题每条额外产生2次输出，因此每模型计划192次输出。测 Flare、Sunburst、Seedream Pro、Nano Banana 2、MAI-Image-2.6、Muse、Wan 2.7、Wan 2.7 Pro，合计1,536次，另计重试和组图专项；接入受限的型号标为未执行。

建议首轮设置：GPT 2.5 high，Seedream 输出 1536²，Google与Wan 1K，其余选择最接近 1MP 的标准输出。由于尺寸不能完全一致，首轮只做业务筛选；进入决赛后再分为统一交付尺寸和各家最佳质量两条赛道，保留原图，不将放大后的图冒充原生输出。Wan连续组图另设专项，不与普通单图题混算。

### 六类必测任务

| 任务 | 主要检查 | 失败示例 |
|---|---|---|
| 白底主图换场景 | 主体完整、真实接触阴影 | 插口、瓶盖、五金件被改变 |
| 人物使用商品 | 尺寸关系、手部接触、遮挡 | 手指融合、手拿位置不合理 |
| 活动海报 | 文字、价格、层级和留白 | 错别字、虚构优惠、价格错误 |
| 单区域编辑 | 修改生效且其他区域稳定 | 改背景时包装也被重画 |
| 跨画幅与系列图 | 裁切、视觉风格、SKU一致 | 长宽比例或配件数改变 |
| 三轮连续编辑 | 未编辑区域累计漂移 | 第三轮后 Logo 和商品形状失真 |

### 评分与否决

建议总分 100：商品结构与身份 35、Logo与文字 20、材质光影 15、指令与构图 15、局部编辑保留 10、系列风格 5。纯文生图题对不适用维度单独报告，不静默改权重后混排。

结构错、规格文字错、Logo 错、配件遗漏或虚构卖点属于直接不合格。其余可用性评分建议达 80 分后进入人工复核。该阈值是业务建议，可按品类调整。

两名评审盲评，随机打乱模型名和输出顺序；有分歧由第三人裁决。所有输出都保留，失败、拒绝、超时和重试分别计数。相同数字 seed 不代表跨模型相同随机条件。

第二轮以30个SKU、6任务、3次重复验证入围模型，每模型540条任务，含三轮编辑共720次输出，另计重试。按SKU汇总和做区间估计，避免把同一商品的重复图当成大量独立样本。该方案尚未执行。

## 10 可复用测试提示词与记录表

每个模型使用相同商品图、场景图和已批准文案。首轮固定提示词，二轮允许每个模型相同次数的提示词优化，同时保留原始成绩。

### 共同约束

图1是唯一商品身份依据，图2为侧面结构补充，图3仅用于场景氛围。保留商品轮廓、比例、颜色、材质、Logo、标签文字、按钮、接口和配件数量。不得添加商品不存在的功能、装饰或标识。无法确认的细节以参考图为准。每次输出一张完整图片。

### 六个任务指令

**A 场景主图：** 将该商品放在真实家居台面，早晨自然侧光，背景有轻微生活痕迹。商品完整呈现，占画面高度约六成，接触阴影自然。不添加文字和人物。

**B 使用场景：** 一位成年人正在正确使用参考商品，朋友近距离随手拍摄的视角。商品尺寸与手部比例真实，不改变结构，避免手指遮挡关键标识。不添加广告文案。

**C 广告版式：** 生成 4:5 广告图，标题必须逐字为“轻松开启每一天”，副标题为“日常好物”，价格为“¥199”。商品位于右下，左上留出清晰文字区域；不得添加其他价格、优惠或认证标志。

**D 局部修改：** 仅把背景台面改成浅灰石材，保持商品本体、位置、大小、包装文字、视角和画面其他物品不变。只调整必要的接触阴影。

**E 画幅扩展：** 将已批准的方图扩展为 9:16，保持原图中央商品像素内容和比例，向上下补全自然环境，不新增商品和文字。若模型无法精确保留像素，记录偏移情况。

**F 连续编辑：** 在同一输出上依次执行“移除左侧道具”“背景变成柔和米白色”“只把标题改为日常新选择”。每轮保存结果，比较商品本体和未编辑区域是否发生变化。

提示词 C 的文案和价格为统一测试内容，不用于真实商品发布。生活方式题不强制加品牌宣传语，避免把广告腔误评为生活感。

### 每次输出至少记录

任务编号、SKU、模型完整 ID 和快照、供应商与地域、提示词版本、参考图哈希与顺序、质量档、请求与实际尺寸、耗时、usage、账单费、错误类型、否决项、各维度分数、是否合格、修改次数、人工分钟数、输出文件路径。

## 11 补充模型与最终采购建议

### Reve 2.1

官方发布页描述原生 4K 和可编辑布局；它在文生图榜单中值得作为高质量对照。[S17] 但更晚的官方帮助页明确 API 于 8 月 14 日停止提供，并安排退还余额。[S18] 因而旧榜单中的 API 单价和 7 月 API 发布文章不能作为当前接入依据。可评估其交互式产品，暂不把官方 API 纳入新生产链路。

### Midjourney V8.2

官方当前默认版本为 V8.2，方向偏审美和个性化。[S19] 适合设计师概念探索，但本报告没有它与核心候选的同配置盲测证据。官方月付计划为 $10、$30、$60、$120；这不是每张 API 价。[S20] 官方说明仅少数明确授权例外提供 API，自动化接入不能预设可行。[S21]

### FLUX.2

适合作为现有工作流的专项补充，而非仅凭知名度纳入本次综合领先名单。官方 FLUX.2 pro 生图 $0.03 起、编辑 $0.045 起；max $0.07 起；成本按分辨率变化。dev 在官方价格页标为本地使用、非商业许可，不能理解为电商免费商用。[S22]

### 建议按场景选路

| 场景 | 第一选择的验证方向 | 需要保留的对照 |
|---|---|---|
| 国内中低分辨率素材批量生产 | Seedream Pro | Qwen Pro 的文字准确率 |
| 国内连续组图与成本优化 | Wan 2.7，难例复测Pro | Seedream的合格率与修图工时 |
| 高价值活动主视觉 | Flare high，再试 max | GPT Image 2 medium 的回归成绩 |
| 高要求局部修图 | Sunburst | MAI-Image-2.6 |
| 多商品与人物合成、4K输出 | Nano Banana 2 | Nano Banana Pro 难例复测 |
| 全球低成本批量探索 | Muse、MAI Flash | 真实SKU通过率与账户稳定性 |
| 设计师手工风格探索 | Midjourney、Reve | 接入方式和人工时间 |

这是一组待验证的模型分工。面向当前电商任务，建议最小验证集合为 Flare、Seedream Pro、Wan 2.7 和 Wan 2.7 Pro；需要多参考4K时加Nano Banana 2，精细编辑占主要工作量时加Sunburst。先测能影响成本和交付的场景。

采购前应固定供应商、地域、模型快照和账户权限，再用真实 SKU 验收。最应避免的三种口径错误：把榜单第一视为商品零失真，把会员额度视为 API 免费，把成功出图视为合格交付。
